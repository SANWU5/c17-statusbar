Android platform zlib is supplied by the operating system.

RAR4/RAR5 are read using libarchive's read-only native decoders. Encrypted, split,
linked or malformed entries are not supported by the C17 importer. No archive-owned
path is extracted or executed. ZIP uses the Java platform reader.

Third-party imported icon images retain their own licenses. They are not bundled
with C17 by default and are not automatically relicensed under GPL-3.0-only.
