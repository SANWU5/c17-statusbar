# 更好的 C17 状态栏 1.8.2

版本号 **1.8.2**，versionCode **75**。本次为正式更新，以下内容对比 [1.8.1](https://github.com/SANWU5/c17-statusbar/releases/tag/v1.8.1)。

## 新增

- **锁屏状态栏区域模糊**：在“锁屏”中设置强度、主要模糊高度、由虚到实过渡高度和颜色遮罩。效果只处理顶部壁纸，向下逐渐恢复清晰；时间、通知和状态图标保持原生绘制。壁纸结果缓存复用，锁屏显隐不逐帧重新计算模糊。
- **流体云展开面强调色**：位于“其他”，使用原生媒体强调色替换展开音乐面板的黑色填充。
- **隐藏充电图标**：位于“电池”，可隐藏内外充电闪电，不改变实际充电状态。
- **网速安全间距**：实时网速可与相邻图标保持距离，水平偏移参与占位计算，减少 Wi-Fi、蜂窝信号与网速相互挤压。

## Bug 修复

- 修复状态栏时间异常偏小、消失和格式显示成省略号。100% 使用系统原生像素字号，比例只应用一次；测量更新旧文字布局缓存，字距不重复计算。按本次要求取消模块宽度上限和自动缩小，完整格式按设定字号测量。
- 保留旧字号配置。确认存在旧低基线时兼容原来的补偿比例，避免升级后再次放大；关闭大小调整时直接使用原生数值，导入、导出与试用回退保留基线信息。
- 修复通知栏上下拉动时右侧状态图标的过渡：只渐隐、渐现，位置保持不变；控制中心沿用原有交接。
- 修复 Wi-Fi 开关前后网速位置变化，以及单卡网络制式文字落入原生角标位置的问题。单卡文字使用独立水平槽位，保留漫游标识和关闭恢复。
- 修复统一圆角与磁贴按压、编辑形变不同步的问题。
- 修复去高光后设备卡片底色不一致。设备区域与普通未激活磁贴使用相同颜色处理，保留原生透明度、自定义活动磁贴颜色和音乐背景。
- 合并磁贴与材质的后台刷新到主线程，修复相关线程异常并减少重复刷新。

## 设置调整

- **文字来源统一列表**：系统字体、苹方、已有开源字体和导入字体集中选择。未下载字体标明“需下载”；下载和导入字体支持管理、重命名与删除，删除正在使用的字体后回退系统字体。来源与许可说明放在页面下方。
- 时钟诊断补充原生字号、应用字号、完整字宽和实际测量宽度，不记录时间文字或通知内容。

## 更新与兼容

覆盖安装后重启 SystemUI 或手机加载新代码，已有配置保留。过大字号或过长时间格式可能占用其他图标空间，请结合屏幕宽度设置。

锁屏模糊当前适配已核对的原生静态壁纸路径；动态壁纸或无法确认的映射保留系统效果。下拉面板自定义壁纸继续停用，没有在本版恢复。

已完成 Debug/Release、关键 lint、101 组生产代码检查、签名及 16KB 对齐检查。本次未安装最终包进行实机视觉、帧率或耗电验收，验证范围见 [验证记录](https://github.com/SANWU5/c17-statusbar/blob/v1.8.2/VALIDATION.md)。
