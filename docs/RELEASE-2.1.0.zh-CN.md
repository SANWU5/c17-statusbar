# 更好的C17状态栏 2.1.0 更新说明

版本 **2.1.0**。以下记录对比正式版 [1.8.3](https://github.com/SANWU5/c17-statusbar/releases/tag/v1.8.3) 的新增、优化与修复。覆盖安装后请重启系统界面或手机加载新代码。

## 版本与对比范围

| 项目 | 公开版 | 2.1.0 正式版 |
| --- | --- | --- |
| 版本 | 1.8.3 | 2.1.0 |
| versionCode | 192 | 293 |
| 发布 / 构建日期 | 2026-10-18 | 2026-11-12 |
| 附属模块 | 1.7 / code8 | 2.3 / code14 |

## 主要变化一览

| 项目 | 说明 |
| --- | --- |
| 扩展插件 | 可在 App 内导入和管理插件，插件有独立设置，开机后自动加载 |
| 界面 30 种语言 | 首次打开先选语言，默认跟随手机系统语言 |
| 系统UI防炸 | 开机动画期间 5 秒内连按 5 次音量上键，可重置系统界面数据 |
| 隐私胶囊 | 相机、麦克风使用时以原厂流体云胶囊提示，可去除隐私小点 |
| 界面风格 | 新增 Material 风格，欢迎页与关于页重做 |
| 状态栏修复 | 网络制式文字、网速、Wi-Fi 与电池的错位、空隙和隐藏图标占位等问题 |

## 扩展插件

新增「关于 → 扩展插件」，插件直接在 App 内导入，不用另装 LSPosed 模块。插件不随安装包提供，需另行导入。

| 项目 | 说明 |
| --- | --- |
| 导入与管理 | 支持 JS / ZIP 插件，可启用、停用、升级、删除；列表支持排序和长按拖动 |
| 插件设置 | 详情分「说明 / 设置 / 管理」三页；支持预设、一键恢复默认和单个插件配置的导入导出 |
| 插件目录 | 可添加第三方 HTTPS 插件目录，下载时核对文件大小与校验值 |
| 自动加载 | 重启手机后无需打开 App，已启用的插件即可加载；安全模式同样适用 |
| 旧版本清理 | 导入新版插件后自动清理旧版本文件，减少存储占用 |
| 自制插件 | 公开插件仓库 [SANWU5/c17-plugins](https://github.com/SANWU5/c17-plugins) 提供插件规范、模板和校验工具，用户可按规范自行开发插件 |
| 收费说明 | 主模块永久免费；扩展插件可能收费，欢迎页与关于页均有说明 |

## 状态栏

状态栏的更新以修正位置和间距为主，另新增隐私胶囊。

| 项目 | 说明 |
| --- | --- |
| 隐私胶囊 | 「状态栏 → 系统图标 → 隐私小点」新增胶囊：相机、麦克风被使用时以原厂流体云显示，不进通知中心；停止使用即收起，显示时长 1 秒起或一直显示；可去除橙色 / 绿色隐私小点及其动画 |
| 网络制式文字 | 按实际字形宽度测量，横向缩放计入占位；预留宽度自动计算；转屏后与 Wi-Fi 共用位置重新取样 |
| 锁屏 / AOD 网络文字 | 单卡网络制式文字在原生重建布局时不再跳过交接，减少偶发错位 |
| 网络切换 | 关闭数据时不再显示旧的 4G / 5G，切换后不再延迟刷新；流体云开合时 5G 不再挤进电池 |
| 间距与空隙 | 原生隐藏或显示为小点的系统提示图标不再占宽度，开关蓝牙 / 定位后不留空格；网速后不再留空隙；「垂直位置调整」只管上下 |
| 控制中心头部 | 按原生容器判断左右，关 Wi-Fi 时网速不再跳到左侧，运营商名称恢复 |
| 动画错位 | Wi-Fi 与电池在进出动画中的横向挤压已修正；通知栏嵌套边距不再裁掉图标 |
| 时间格式 | 支持中文、英文和混排及对应预设 |
| 天气图标 | 改为圆润风格，与文字高度对齐 |

## 控制中心与通知

这部分以材质修正和流畅度改进为主。

| 项目 | 说明 |
| --- | --- |
| 详情面板材质 | 不再强制灰色底板，保留原生玻璃、去高光和自定义颜色 |
| 通知列表流畅度 | 通知更新时不再重复扫描，角标查找更快；快速滑动后的惯性滚动卡顿减少 |
| 同应用小堆叠 | 去掉后卡透明度的重复写入，修正与原生组标题栏反复争抢显示，开启后滑动更顺（仍可能卡顿，ColorOS神奇代码） |
| 静止重画 | 面板盖住状态栏时不再播放电池充电动画，减少下拉面板静止时的重画 |

## 应用界面、欢迎页与多语言

App 界面现在有 30 种语言和三种风格，欢迎页与关于页都重新整理过。

| 项目 | 说明 |
| --- | --- |
| 30 种语言 | 全部界面文字提供译文，缺译文时显示英文；设置搜索同时匹配中文和当前语言 |
| 首次打开 | 先显示 30 种语言轮流的「欢迎」和语言列表，未选过时默认跟随系统语言；首屏也可选界面风格 |
| 欢迎页与声明 | 功能分项介绍，永久免费与插件可能收费的说明，许可与免责折叠展开；首次需逐字输入确认短句 |
| 更新后显示欢迎页 | 版本号变化后再显示一次，已确认过免费声明的只需打开「同意」开关 |
| 支持与交流 | Telegram 群组、微信 / 支付宝收款码、加密货币捐赠（Ethereum (ERC20)、Tron (TRC20) 各一个地址），欢迎页与「关于 → 联系与捐赠」都可复制 |
| 界面风格 | 新增 Material，与 Miuix、COUI 三选一；COUI 底栏改为悬浮磨砂胶囊，可使用液态玻璃底栏；各页滚动渐隐统一 |
| 关于页与启动 | 关于页收成「常用 / 维护 / 关于」三组；Android 12 及以上加入约 1.5 秒的原生启动动画 |

## 附属模块与系统UI防炸

附属模块从 1.7 升到 2.3，新增「系统UI防炸」，用于系统界面反复崩溃、开不了机时自救。

| 项目 | 说明 |
| --- | --- |
| 触发方式 | 开机动画期间，5 秒内连续短按音量上键 5 次，重置系统界面的用户数据；中途按其他键作废。不用电源键和音量下键，避免与关机菜单、安全模式冲突，代价是音量会调高 5 格 |
| 触发保护 | 只在开机动画期间监听，每次开机最多触发一次，不抢占按键；App 与附属模块网页都有开关（默认开启） |
| 附属模块界面 | App 内与管理器网页统一为精简版，默认只显示状态、开关、缓存和主要操作，用法、统计和日志折叠 |
| 历史配置残留清除 | 「关于 → 配置管理」新增入口，连同当前配置、插件和导入资源一起清除，需 Root，有两次确认 |
| 更新方式 | 更新 APK 后仍需在 App 内单独更新附属模块，重启手机后生效 |

## 性能与问题修复

除上文各节的修复外，还有以下整体改进。

| 项目 | 说明 |
| --- | --- |
| 状态栏位置 | 修改设置后不再跳位；流体云出现时位置更新更及时；不再短暂露出未加边距的原生位置；负间距时下拉头部切页不再被裁切 |
| 运行开销 | 未开启图标管理时不再安装相关全局钩子；状态栏排列的测量与布局开销降低 |
| 稳定性 | 改进配置保存失败后的恢复、缓存与回收、通知恢复，以及 Root 操作的互斥与日志 |

## 升级须知与已知问题

**升级须知**

| 项目 | 说明 |
| --- | --- |
| 覆盖安装 | versionCode 293 高于 1.8.3 的 192，可直接覆盖安装；安装后重启系统界面或手机加载新代码 |
| 欢迎页 | 升级后首次打开会显示欢迎页，确认后才能修改设置 |
| 系统UI防炸 | 会重置系统界面的数据（例如控制中心磁贴排列），请仅在系统界面无法正常启动时使用 |
| 图标库 | 与 1.8.3 相同，公开包内置原创C17示例库，不附带整套PUI图标套装；自备 v3 图标包可导入 |

**已知问题**

| 项目 | 说明 |
| --- | --- |
| 多语言 | 译文为机器翻译，部分说法可能不够准确，欢迎反馈；从右到左的语言和长译文的排版可能有问题；少量提示、诊断日志和系统界面一侧的文字仍为中文 |
| 通知列表 | 快速滑动后的惯性滚动仍可能偶发卡顿 |
| 隐私胶囊 | 显示时状态栏左侧可能隐藏时间而保留通知图标，收起时可能有一两帧文字重叠 |
