# 时钟、控制中心配色与模块激活检测修复

记录日期：2026-09-30（Asia/Shanghai）。基于主分支 `fdc1de3`，版本仍为 1.14.1 / 29，作为本地测试构建。

## 修改

- 控制中心磁贴的活动填充色、渐变终点色按用途分组，每组并排编辑浅色、深色背景，与其他颜色设置页共用色卡和 HSB 编辑器。
- 浅深预览随透明度、渐变方向等设置即时重绘，并根据可用宽度调整图形尺寸。
- 通知页、控制中心、锁屏的运营商独立开关使用统一外观。
- 通知栏的 `SimpleQsClock`、控制中心的 `QsClock`、共享父类 `OplusQSClock` 及其子类纳入时钟修改范围。默认跟随状态栏的格式、字体、大小、字距、颜色和位置设置。
- 增加“通知栏与控制中心时钟”设置页，可独立修改格式、位置、大小、粗细、字距和颜色。独立调节默认关闭；关闭后恢复跟随状态栏。旧配置无需迁移。
- 原生 `calculateSecondTextMaxWidth()` 会直接将 Paint 字号改回 `stat_clock_size`。现在在测量后恢复自定义样式，并按字号比例校正纯文字宽度，保留原生数字宽度算法和外层 padding、字体比例及动画计算。
- 设备行的五种原生卡片仅修改已确认的内层底板，统一采用磁贴配色，同时保留玻璃高光、图标、文字和点击行为。
- 补齐按压、切换动画中的原生灰度插值底板识别，避免中间帧恢复原生填充。普通磁贴关闭后的原生未激活样式继续由系统处理。
- 启动、返回应用或手动点击“重新检测”时，进行一次激活检测。通过随机挑战和来自当前 SystemUI 进程的有效报告确认 LSPosed 注入；成功、超时或离开应用后清理检测观察器与超时任务。没有定时轮询或循环检测。
- 检测未完成、失败或不可用时锁定设置与导入；设置编辑器在提交时再次检查，避免旧对话框绕过门禁。移除“打开 LSP”入口。
- 字体导入先在后台验证、暂存，最终发布与选项提交同生命周期回调串行执行。提交失败时恢复旧字体及选项，避免失去激活状态时留下部分导入结果。
- 增加“重启系统 UI”按钮，后台申请 Root，检查原进程退出及新进程出现后报告结果；重启完成后再次检测模块激活。

本地原生类证据显示，过渡的 `StatusBarFakeFrame` 绘制真实状态栏时钟，而真实通知栏终点为 `SimpleQsClock`。本次补齐终点的样式处理；原有缩放、基线、位移与透明度动画由系统继续处理。运营商替换配置继续独立，锁屏时钟不纳入新的普通视图识别。

## 验证

- 37 个生产 Java 源文件使用 Android API 35、LibXposed API 101 从空输出目录编译通过。
- 全部 32 组检查通过，涵盖独立时钟、原生字号回写恢复、反复测量不累计、关闭恢复、独立运营商设置、设备行配色、按压插值、激活挑战、重启结果、设置提交门禁及字体事务回滚。其中时钟 337 项、磁贴 514 项、激活挑战 31 项、字体事务 54 项。
- 资源编译、链接和 DEX 构建通过。
- 测试 APK 的 v2/v3 签名和 4 字节对齐验证通过；模块入口、作用域、内置字体及完整 GPLv3 文件核对通过。
- OnePlus 13 / ColorOS 17 / Android 17 实机验证：旧注入版本无法通过新版检测时设置锁定；重启系统 UI 后识别 `LSPosed 2.2.0-it` 并解锁。
- 实机点击重启按钮，SystemUI 原进程退出、新进程出现，界面重载后再次识别激活。Root 不可用时显示失败结果。
- 激活检测结束后，系统内容观察器中没有残留 `runtime_status` 检测观察器。
- 实机分别设置状态栏 `HH:mm` 与通知栏 `HH:mm:ss`、不同大小及位置；通知栏显示秒数，状态栏保持时分。横屏通知栏仍显示独立格式。
- 浅色与深色分别使用明显不同的测试颜色，设备整排、活动磁贴及滑块填充正确响应，横屏设备行仍应用配色。
- 浅色、深色各连续点击自动旋转磁贴 6 次并录屏，逐帧检查原生按压、图标和状态变化过程，未发现中间帧白色闪回；测试后恢复旋转状态。
- 关闭独立调节后，通知栏恢复状态栏的自定义时分格式及大小；通知栏和控制中心各连续展开、收起 5 次，样式保持。
