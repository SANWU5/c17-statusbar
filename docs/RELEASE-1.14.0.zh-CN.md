# 更好的C17状态栏 1.14.0

作者：aiingjie · 正式版：v1.14.0 · versionCode：28

## 更新内容

- **磁贴边缘渐隐**：默认保留原生左右滑动，只在左右边缘渐隐。修复先裁切再渐隐留下的直线，以及效果越界覆盖邻区的问题；顶部和中间不再叠加整层透明衰减。横屏／竖屏独立开关和已有范围、位置配置保留，高级模糊默认关闭。
- **全局磁贴调色**：浅色／深色主题分别调整原生活动填充的颜色、透明度和渐变，统一应用于支持的 Wi-Fi 内圆、音量／亮度填充和其他活动磁贴；保留玻璃外层、边框、高光及原生图标文字和动画。此功能默认关闭。
- **配置导入／导出**：通过系统文件界面保存、选择 JSON；导入先完整检查，再确认应用。字体文件、日志及本机信息不随配置传输，缺少自选字体时使用系统字体。
- **Wi-Fi 位置修复**：隐藏角标和上传下载箭头后，其装饰布局不再随活动状态改变图形测量位置；关闭隐藏时恢复系统最新显示状态。

## 安装与使用

覆盖安装同签名 APK，在 LSPosed 中启用模块并选择 SystemUI 作用域。代码更新后重启 SystemUI，日常参数变更即时生效。原有状态栏、三处运营商文字、电池内充电切换、精细数值、HSB 颜色、字体及可选日志功能继续保留。
