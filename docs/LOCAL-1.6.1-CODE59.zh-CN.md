# 1.6.1 / code59 本地修订与待用户验证

本轮继续使用版本名 `1.6.1`，versionCode 为 `59`。尚未上传或公开发布；正式构建、签名、覆盖安装及用户验收由根任务分别记录，本文不将 code58 或更早版本的设备观察当作 code59 已通过。当前用户反馈为系统提示图标设置无效、通知堆叠交互及横屏收起表现需要修正；以下为本轮实现规则和待验证范围。

## 系统提示图标

入口：配置 → 状态栏 → 系统提示 → 系统提示图标。主开关默认关闭，最多显示数量默认 `14`，附加间距默认 `0`；已有保存值保留。只管理蓝牙、定位、闹钟、勿扰等真正的原生系统提示，不把通知图标、Wi-Fi、蜂窝信号、电池和网速纳入数量或位置控制。

本机原始 SystemUI 的正常图标顺序中，网速、蜂窝和 Wi-Fi 前后均可能存在系统提示。旧实现遇到这种交错结构会整组回退原生，可能导致全部设置没有效果。本轮按真实原生结构修正：**数量按全部可见系统提示及所设优先级选择，排列只调整各连续提示区段，不跨越网络区域。** 中文名称与 ASCII 系统标识仍可用逗号分隔，原生已阻止、忽略或隐藏的图标不会被强制显示。

水平位置与间距使用各提示区段的实际可用空间，保持网络区域及其他原生控件边界；没有足够空间时保留原生水平位置。纵向位置依据现有祖先的实际裁剪边界，避免把仅一个图标高的测量容器误认为不可移动范围；不扩大父窗口、不改裁剪设置、不改变原生图标大小、颜色及动画。RTL、安全模式、关闭、解绑和卸载仍恢复对应原生布局。未知缩放或无法确认的结构保留原生。

本轮已完成针对真实交错顺序和非裁剪容器结构的桌面定向验证，包括重复调用的缓存复用；未进行手机操作，实际生效仍待用户使用新包反馈。没有新增绘制时逐帧扫描或无界刷新。

## 通知堆叠与横屏大时钟

整体“堆叠通知”与“同类通知堆叠”继续是两个独立、默认关闭且可同时开启的开关，已保存配置按原值保留。完整通知默认 `1` 条，建议范围 `1–5`，合法更大正整数仍可手工输入；按实际通知数量处理，不生成通知或按输入创建巨大列表。

整体堆叠沿用原生通知的滑动展开/收起交互，**不再用第一次点击卡片代替展开**。保留原生点击、长按、侧滑删除与真实卡片尺寸，未知结构继续交给系统处理。整体尾部层数及曲线遵循系统原生滚动布局；旧三层尾宽参数保留存储兼容、隐藏入口，不再自行缩放、裁剪通知。

同类堆叠仅处理系统已有消息组，不把不同应用的独立通知拼成一组。折叠时优先最新收到的消息，最多三层原生底沿；展开时保留原生应用名称与收起入口，仍由系统管理组内展开动画和消息交互。排序提前到系统测量前，避免更新目标时换首项而沿用上一张卡片的高度缓存；组展开、拖动和回弹期间保持系统顺序。

竖屏、横屏大时钟继续各自独立开启。横屏通知上滑时大时钟随真实滚动隐藏，通知字体、图标、内边距和真实高度保持原生，清除按钮继续按实际空间避让。横屏收起及两种堆叠叠加的最终设备表现待用户验证。

## 音乐背景与网络角标

识别到真实新音乐封面后，先显示从新封面取得的纯色，避免继续显示上一首封面；最后一次变化后等待 `1000ms`，在后台准备新的封面/模糊材质，完成后用 `240ms` 淡入新背景。等待时间和淡入时长是两个阶段，不逐帧重做模糊。无新内容时复用缓存；关闭、安全模式、解绑及失败时按当前原生材质恢复。原生动态材质、GPU开销与不同应用的封面切换需设备验证，不把桌面缓存计数写成帧率或耗电改善。

蜂窝“隐藏系统网络角标”接入实际 Compose 渲染路径，不只依赖旧 View 来源；原生角标与模块文本按明确开关控制。旧 `data_single_enabled` 键仅保留保存、读取兼容，不再作为额外功能门控，也不新增该入口。蜂窝数据箭头继续强制隐藏，其他功能默认关闭，用户已保存的样式与位置不重置。

新增“状态栏 → 原生角标调整”，默认关闭，支持水平位置、垂直位置、大小和字重；仅在“网络制式文字”关闭时生效。冲突时保留参数并暂停效果，仍可关闭已保存的角标开关。蜂窝样式开启不会再强制使用大网络文字布局；独立文字关闭后恢复真正原生角标，隐藏角标开启时不另输出网络文本。

## C17 高光去除

控制中心按真实原生模糊控件的 owner 建立材质范围，不依赖硬件绘制是否经过外层 View.draw。仅接收系统本次返回的模糊材质，不增加查询；移除光学边缘、内阴影及独立滑块描边，保留模糊、原生形状与点击行为。开启自定义亚克力底色时沿用独立深浅背景色，关闭底色时保留原填充；关闭功能或安全模式恢复原生。最终视觉效果待新包实机反馈。
