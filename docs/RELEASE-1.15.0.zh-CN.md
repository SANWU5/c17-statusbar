# 更好的C17状态栏 1.15.0

作者：aiingjie · versionCode：30 · LibXposed API：101 · GPL-3.0-only。

## 更新内容

- **整套 UI 重做**：原生 HyperOS 风格，首页、状态栏、下拉面板、设置四页；新增功能搜索、参数分组与可折叠卡片，统一深浅主题、数值编辑与 HSB/透明度调色弹窗。
- **配置持久化**：检查完整配置快照，拒绝不完整结果；即时保存内存值、后台合并确认落盘与最后有效备份，应用失败时尝试恢复之前成功配置。合法的零值、透明色和空文本保留。
- **通知堆叠**：折叠时最多三张完整通知，后方最多三层独立宽度底边；不删除真实通知。圆角根据实际可见薄窗解算，背景玻璃与高光使用同一裁剪窗口。
- **音乐卡片**：封面居中铺满背景，支持模糊与透明度；原始小封面支持反色或自选颜色外发光。浅深场景分别设置，保留原生玻璃、高光和播放操作；此功能默认关闭。
- **减少重复计算**：合并同帧配置通知，跳过未改变的完整快照；时钟文字、时间格式、反射和几何缓存去重。封面过滤由单一有界后台任务按变化执行，移除设置底栏的实时背景抓取。
- **通知页大时钟**：加入独立原生数字切换、同字重高度轴收起、玻璃边框、时间与通知安全距离、空间边缘过渡，以及清除按钮颜色/渐变/透明度等设置。状态栏右侧图标保留固定锚点和原生透明度交接。

## 安装

覆盖安装同签名 APK，LSPosed 启用模块并选择 SystemUI 作用域；更新代码后重启 SystemUI。日常设置由通知即时应用。保留原有配置，旧完整卡片数大于 3 的保存值按最多 3 生效。

此包加入既有 GitHub 正式版到当前开发签名的 Android 升级链：Android 8.x 继续使用旧正式版证书，Android 9+ 使用当前证书并携带旧正式版的有效继承证明。旧正式版与当前 native27 开发版的更新路径均已核对签名元数据；尚未实机执行覆盖安装。其他自行签名的包仍不能直接覆盖。
