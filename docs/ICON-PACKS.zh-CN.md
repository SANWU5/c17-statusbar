# 自定义系统图标

入口：**配置 → 其他 → 图标库 → 自定义系统图标 → 管理图标库**。

此功能自 1.8.1 提供。

## 导入与管理

可从文件选择 ZIP、未加密的单卷 RAR4/RAR5，或输入 GitHub 仓库、下载链接。导入后默认禁用，开启总开关及对应库的开关后生效。

新导入的库默认供“逐项替换”使用，启用来源库不会自动改变整套图标。如希望整套替换，在该库中打开“整库自动匹配”；已有整库配置继续沿用原使用方式。

- **排序**：长按名称上下拖动，点击“确定”保存。多套同时开启时按列表顺序匹配，靠前的优先。
- **重命名**：只改变管理页名称，不改变图标文件与已保存的匹配顺序。
- **禁用**：保留文件与名称，暂时跳过该库。
- **删除**：先移除该库的启用记录，再删除私有文件。其他库和原生图标保留。

最多保存 32 个库、同时开启 16 个。未提供或读取失败的图标继续匹配后面的库，最终回退到当前系统或 PUI 样式。用户配置只包含库 ID、启用状态和顺序，不包含图片文件；换机需重新导入。卸载或“一键删除所有配置”会清理导入文件。

## 逐项替换

入口：**配置 → 电池 / Wi-Fi 图标 / 蜂窝信号 → 自定义图标**。也可在 **其他 → 自定义系统图标 → 逐项替换图标** 集中设置。

先选择目标，如蓝牙、定位、某档 Wi-Fi 或电池，再从已启用图标库中选择替换图案。图案会显示缩略图，可将同一库或不同库中的图案分别指定给不同目标。仅更改选中的目标，其他图标继续自动匹配。

逐项设置优先于整库顺序；蓝牙的开启/关闭状态设置优先于通用蓝牙设置。选择“恢复自动匹配”后删除该项目的指定关系，重新查找启用“整库自动匹配”的库；没有整库来源时使用原生图标。来源库被禁用、删除，或文件无法读取时，也会自动回退，不改变系统原本的图标显示条件。

当前 ColorOS 没有为未连接 Wi-Fi 绘制状态栏图标，因此不提供该目标入口；不会把 Wi-Fi 数据活动箭头当作断开图标。图标包保留 `wifi.none` 字段以兼容既有格式。系统本来隐藏的提示图标也不会因为替换图案而出现。

## 替换范围

Wi-Fi、电池、单排/双排蜂窝信号，以及蓝牙、定位、闹钟等原生系统提示图标。双卡按各卡实时信号等级分别使用资源，不使用固定双卡图片。

替换只改变图案，保留控件原生尺寸与布局、现有位置/大小调整，以及系统出现/消失动画。图片使用透明蒙版着色：电池整体使用轮廓色，不能分别设置图案内的进度色和背景色；动态百分数及充电提示继续独立绘制。包内图片的 RGB 不用于显示。

图标库不替换时间、网速文字、网络制式文字、数据箭头或应用通知图标。应用通知图标另有“指定应用通知图标”入口，可从系统应用或非系统应用中选择，按应用替换为文字、表情或另一个已安装应用的彩图；来源应用卸载时使用原生图标。通知图标区域使用整体爱心、文字或图片模式时，整体模式优先。

## 制作规范

[独立规范仓库](https://github.com/SANWU5/c17-icon-packs)提供状态映射、JSON Schema、原创示例和制作工具。[示例下载](https://github.com/SANWU5/c17-icon-packs/releases/tag/v1.0.0)可直接导入。原有 PUI 资源的许可不变，规范仓库未转载手机提取的资源。

文件校验、图片归一化与解码在后台执行，绘制阶段只读缓存，不反复读文件或解码。所有启用库共用 4M 像素蒙版预算；未适配的槽位及被高优先级覆盖的资源不占用图片缓存。

## PUI 主题

管理图标库中点击“导入 PUI 主题”，选择用户自己的 ColorOS 17 PUI 主题 ZIP。模块只读取已知信号和系统提示资源，转换成可逐项选择的图案，不安装主题里的 APK，也不执行其中的代码。未提供完整图案的状态保留原生，电池动态组件不拼成固定电量图片。

PUI 原素材没有随本项目重新分发。导入后的库默认关闭，启用后再选择目标图标；管理、排序和删除方式与其他图标库相同。v2 图标库允许明确声明 `fallback: native` 的部分状态，v1 完整状态规范继续兼容。
