# 更好的 C17 状态栏 1.8.1

版本号 **1.8.1**，versionCode **69**。变化对比 [1.7.2](https://github.com/SANWU5/c17-statusbar/releases/tag/v1.7.2)。

## 新增

- **自定义系统图标**：支持 Wi-Fi、电池、蜂窝信号及蓝牙、定位等提示图标逐项替换。电池、Wi-Fi、蜂窝信号页面增加对应入口；图标库可排序、重命名、禁用和删除，支持 ZIP、RAR、GitHub 及用户提供的 PUI 主题导入。制作规范在 [独立仓库](https://github.com/SANWU5/c17-icon-packs)维护，未提供的状态保留原有图标。
- **指定应用通知图标**：区分系统应用和非系统应用，可替换为文字、表情或另一个已安装应用的彩色图标。通知图标区域增加独立间距调整，保留图标原始大小。
- **经典模式文字自定义**：运营商与时间、日期分开设置格式、位置、大小和颜色。按实际面板模式暂停冲突的大时钟及相关堆叠功能，原配置保留。
- **原生网络角标**：角标1、角标2分别设置字体、字重、位置、大小和隐藏。仍需先关闭自定义网络制式文字；数据活动箭头保持独立设置。
- **网速位置**：提供时钟左侧、时钟右侧、网络区域边缘等位置，保留系统数字和单位布局。
- **悬浮通知高光**：顶部横幅通知可独立去除高光，统一卡片颜色可独立使用。

## Bug 修复

- 竖屏原生大时钟恢复展开、收起高度变化。新增“屏幕内间距设置”，控制左右留白；下拉和列表滑动改变字形高度时，保持文字宽度稳定。横屏及其他字体保持单一大小设置。
- 修正尺寸基准重复计算、控件复用和原生布局恢复，避免通知图标等组件反复缩小或放大。
- 主信号单排补齐独立双卡布局适配，同时隐藏对应副卡角标；双排模式保持原有显示。主卡信息暂未就绪时保留原生显示。
- 解除角标位置调整时的文字边界和父容器裁切，移动整行文字；关闭或解绑后恢复原生位置和裁切。
- 原生角标调整覆盖独立信号控件，修复系统精简绘制接口导致设置无效的问题。文字样式与绘制偏移独立接入，关闭时恢复原生样式。
- 锁屏日期适配系统动态加载的时钟组件及原生文字更新；保留原生文字尺寸和解锁交互。
- 状态栏收回时复用原生绘制缓存，减少末段交接时的跳动；横竖屏时钟测量彼此隔离。
- 完整迁移历史配置，保留已保存的数值；不完整或类型错误的开机快照仍使用原有恢复策略。

## 设置调整

- 图标库设置改为普通页面，分类标签、列表和返回操作与其他设置页统一。
- 原生大时钟按方向与字体区分可用参数。恢复默认配置不启用功能；已保存的设置继续保留。

## 移除与停用

- 下拉面板自定义壁纸暂时强制停用，标注“未完成的开发”。保留已存图片和参数，当前不进行绘制或后台解码。
- 大时钟原有的展开、收起比例入口由字高和屏幕内间距设置替代，旧字段仅保留配置迁移兼容。
- 经典模式下冻结分离式大时钟及冲突的通知堆叠功能，切回分离模式后按原设置恢复。

## 更新说明

本次为正式版。已有配置保留，覆盖安装后重启 SystemUI 或手机加载新代码。功能主开关默认关闭，只有超出滑块建议范围的合法数值才进入20秒确认试用。

PUI 原素材不随项目重新分发，可在管理图标库中导入自己的主题 ZIP。图标库和字体文件不包含在配置导出文件中，换机需重新导入。

构建、检查和实机验证范围见 [验证记录](https://github.com/SANWU5/c17-statusbar/blob/v1.8.1/VALIDATION.md)。
