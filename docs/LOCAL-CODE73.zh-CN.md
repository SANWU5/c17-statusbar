# 1.8.1 / code73 本地修复

> 历史原型记录，已由 [code74](LOCAL-CODE74.zh-CN.md) 取代。code73 的槽位适配与均匀模糊不符合最新要求，不代表当前实现。后续只读采集确认手机已安装 code73；下文“没有安装”指该原型编译阶段的动作记录。

修正状态栏自定义时间格式被截断的问题。ColorOS 的时钟与通知图标是叠放在同一容器中的两条分支，旧宽度算法没有扣除通知分支，导致时钟测量空间失真。现在按真实时钟槽位计算，过长格式只在时钟槽位内适配；保留原有格式、字号和位置配置，不迁移或重置用户值。诊断会提供原字号、实际字号、适配前后文字宽度、可用宽度及适配比例，不记录时间文字和通知内容。

锁屏顶部模糊改为单个系统合成器模糊层，删除造成截图横条的多段模糊层。模糊和颜色遮罩只位于锁屏壁纸层，前景时间、通知和状态图标仍由系统绘制。`下沿延展高度` 作为兼容参数保留，决定整块连续模糊区域的额外高度。

## 需要手机确认

1. 状态栏格式依次试 `HH:mm`、`HH:mm:ss` 和 `M月d日 {周} HH:mm`；不应显示 `...`，通知图标仍应完整。对比 100% 与当前字号配置，改变格式后检查文字是否在真实时间槽内恢复大小。
2. 在日志页查看 StatClock 项：`nativePx` / `resourcePx`、`appliedPx`、`requestedWidth`、`desiredWidth`、`availableWidth`、`outgoingWidth`、`fitScale` 应互相合理；日志不包含实际时间文字。
3. 锁屏打开模糊，检查顶部壁纸应连续模糊，没有水平分层条纹；解锁后日期、状态图标和通知保持清晰。调整模糊高度、下沿延展高度和颜色遮罩后，再检查亮屏锁屏、熄屏/AOD、唤醒及解锁过渡。
