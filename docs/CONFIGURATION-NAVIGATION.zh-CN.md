# 1.7.2 / code64 位置与样式分离

通知栏与控制中心时钟关闭独立设置后，跟随状态栏的格式与文字样式，位置保留原生布局，不继承状态栏水平或垂直偏移。单独开启下拉时钟的位置调整才应用本页坐标。

蜂窝位置与网络文字设置覆盖已识别的原生单卡绑定路径；原有配置键和界面入口保持不变。更新后重启 SystemUI 或手机。检查范围见 [code64 说明](LOCAL-1.7.2-CODE64.zh-CN.md)。以下为历史分类记录。

# 1.7.1 / code63 配置分类与当前入口

1.7.1/code63 正式包已覆盖安装，用户已确认发布 GitHub。本节为当前规则；[发布说明](RELEASE-1.7.1.zh-CN.md) 对比上一公开正式版 1.6.0，实际检查范围见 [验证记录](../VALIDATION.md)，不将发布授权视作全部实机验收。

| 分类 | 入口分组 |
| --- | --- |
| 状态栏 | 时间与电量、网络信号、通知显示、系统提示、文字字体 |
| 通知栏 | 时钟与日期、通知显示、清除按钮、界面文字 |
| 控制中心 | 磁贴与滑块、音乐卡片、顶部时间与文字 |
| 锁屏 | 日期与文字、提示图标 |
| 其他 | C17 高光去除与界面材质 |

- **堆叠通知**同时可从状态栏和通知栏的“通知显示”进入，两个入口使用同一配置。竖屏由主开关控制；横屏需主开关及“横屏也生效”共同开启，横屏开关默认关闭，不依赖大时钟。
- **同类通知堆叠**入口已隐藏，默认值与运行值均强制关闭；旧保存值或导入值不能重新开启。原生系统自行形成的应用消息组继续使用原生交互。
- **原生角标调整**位于状态栏 → 网络信号，仅关闭自定义网络制式文字时生效。**数据小箭头**默认隐藏，可在同一详情独立开启，其位置、大小和浅色/深色颜色不依赖角标主开关。
- **横屏清除按钮**位于通知栏 → 清除按钮，位置和配色均与竖屏分开保存；横屏颜色开关独立于位置开关，可分别设置浅色/深色底色、透明度和渐变。
- **隐藏桌面图标**位于主页最下方，可从兼容的 LSPosed 模块设置入口重新打开应用并恢复。关于页保留捐赠、日志清理、配置重置和更新入口。

横竖屏大时钟分别开启和保存；C17 材质集中于“其他”，通知栏与控制中心范围独立设置，磁贴颜色及音乐封面背景保留各自配置。网速样式固定为系统布局，刷新间隔使用毫秒。锁屏日期显示仍待本次正式包实机复核。

# 历史：1.7.0 / code61 分类调整

配置为状态栏、通知栏、控制中心、锁屏、其他五类。C17 去高光及材质只从“其他”进入，通知栏与控制中心范围独立选择；可另外统一通知底色。原有清除位置设置改为竖屏，横屏清除位置单独提供，两个方向不互相覆盖。

“锁屏”新增年月日/星期格式和隐藏小锁；日期示例 yyyy年M月d日 {星期}，保留原字体字号。制式文字入口图标为 5G，原生提示图标入口为齿轮。网速样式入口移除，强制系统原生样式，刷新与文字调节保留。

两种堆叠均在“通知显示”中并可同时开启；同类功能处理已有原生通知组，系统不建组的消息不伪造摘要。当前材质允许磁贴填色、音乐封面与去高光共存，以下旧版本描述仅作为历史。

# 历史：1.6.1 / code58 配置分类与详情整理

本文对应本地 `1.6.1` / versionCode 58，尚未公开发布，阶段构建和实机结果待最终复核。底部导航保留“主页、配置、关于”，使用贴边、无阴影的普通底栏。配置按四种实际界面分类，搜索定位具体参数；完整规则见 [code58用户说明](LOCAL-1.6.1-CODE58.zh-CN.md)。

| 分类 | 入口分组 |
| --- | --- |
| 状态栏 | 时间与电量、网络信号、通知显示、系统提示、文字字体 |
| 通知栏 | 时钟与日期、通知显示、通知栏文字 |
| 控制中心 | 磁贴与滑块、音乐卡片、玻璃材质、顶部时间与文字 |
| 锁屏 | 锁屏运营商 |

同类入口放在一张列表卡内，短详情直接展开。位置、大小、颜色的启用开关与相应参数放在同一节，不再集中堆在独立开关列表。

四个分类标签均分一行空间，通过实际文字测量适配字号，完整展示“状态栏、通知栏、控制中心、锁屏”；去掉黑色点击框。仅标签局部调整字号，其他页面文字继续使用系统字号。

状态栏新增“通知图标区域”，主开关默认关闭。显示方式为原生通知图标、单个爱心、自定义符号或文字、自定义图片；模式相关的文字或图片行按当前选择显示，全局搜索仍可直接找到隐藏行。符号或文字最多12个 Unicode 码点，图片支持PNG、JPEG、WebP且最多2MB；未导入图片时保留原生通知图标。导入图片不会自动开启主开关。位置、大小与浅深背景颜色同页设置，图片内部版本号不出现在界面中。

最大显示数量有独立开关，默认关闭，仅原生图标模式生效。手动输入必须为非负整数，可超过滑块建议范围；0 表示不显示图标，不删除或关闭通知。切换到爱心、文字或图片模式后，不应用原生图标数量设置，搜索仍可定位这些参数。

图片导入会保持宽高比，将最长边缩至不超过128px并保存为应用私有 PNG；不长期保留原文件访问权限。导入文件与图片模式、名称、版本配置一起提交，失败时尝试恢复原文件及配置。SystemUI 通过只读接口读取，并校验文件版本；图片尚未加载或校验失败时继续显示原生通知图标。

电池详情增加“电池内文字”一节，独立调整水平与垂直位置、字号、字重和字距，关闭该节开关时恢复原生文字样式。网络文字仅在确认 Wi-Fi 和蜂窝数据开关均关闭时自动隐藏；关闭 Wi-Fi 但蜂窝数据状态未知，或仅未连接网络时，不据此隐藏。

蜂窝详情提供“无网络标识间距”，独立选项默认关闭，间距默认是相对原生的0dp增量。开启蜂窝功能与此选项后，仅在 Wi-Fi 图标和蜂窝网络制式文字均确认未显示、原生最末可见图标是紧邻电池的蜂窝图标时生效。关闭、0dp、状态不明或原生布局不匹配时使用原生间距；这个条件与前述网络开关关闭时隐藏文字的规则分开判断。

字体详情提供 10 种真实可变字体设计，2 种自身覆盖简体中文，其余 8 种拉丁字体使用系统中文回退。这是可选字体目录，不是热门排名。首次选择按需下载，已下载文件经校验后可离线复用；下载取消、失败、应用离开或编辑权限变化时保留原字体。选用字体不自动开启字体主开关，完整来源与许可见 [字体库说明](FONT-CATALOG.zh-CN.md)。

数字参数可手动输入，建议范围内合法输入直接保存，只有建议范围外手工数值先试用20秒，确认后保存；取消、超时或离开恢复原值。输入必须为可表示的有限数值，运行时保留绘制保护。统一圆角硬限制0–30dp，通知数量须合法整数。配置页无实时预览，试用结果以SystemUI实际显示为准。

输入弹窗按实际参数显示所属板块、小节、单位、当前值、默认值和建议范围，不将滑块步长当作输入精度限制。通知数量、圆角和所选字体字重各有专门说明；时间格式与普通文字分别提示语法和长度。数值键盘支持小数，可切换科学计数和正负输入。试用确认显示上次确认值与本次输入值，长说明可滚动，确认、保存和取消按钮保留在独立区域。

长详情按场景分节：大时钟为时间、日期、通知、动效、底部；电池为样式、布局、电池内文字、颜色；磁贴和音乐分常用、浅色、深色界面。竖屏与横屏大时钟分别打开详情、保存参数和启用，新增横屏开关默认关闭。通知显示中的“堆叠通知”沿用整体Stack开关、“同类通知堆叠”处理系统消息组，两者独立于时钟、可同时开启，默认关闭，不删除真实通知。

旧顶部图标切页入口隐藏，运行时强制关闭旧值，不提供固定RIGHT副本。当前方向的大时钟仅替代通知页时钟，关闭、安全模式、锁屏和解绑恢复对应原生显示；控制中心继续使用自己的时钟。系统提示图标另有独立默认关闭主开关，最多数量默认14、附加间距默认0，支持位置及中文/ASCII优先级，不控制通知、网络、电池或网速。

音乐背景在最后一次内容或样式变化后等待1秒，以160ms淡出旧封面到当前原生高光材质，再以240ms淡入新封面；复用已准备结果，不逐帧执行模糊。关闭或安全模式恢复原生。C17去高光另可设置浅/深亚克力底色与透明度，开启底色时优先于磁贴填色和音乐封面；关闭底色可以继续去高光。

关于页保留应用图标、名称、作者aiingjie及合作联系，捐赠入口点击打开原图弹窗，页面不铺图。提供清空历史日志、确认删除所有配置、手动检查更新；已授权Root可点击下载本项目正式更高版本，经大小/摘要/包名/版本/签名核验后覆盖安装，自动清理临时包，不静默更新。最底隐藏桌面图标默认关闭，不需要Root或LSP权限，只切换Launcher alias并保留MODULE_SETTINGS恢复入口。

通知栏、控制中心、锁屏文字仍共用原有 `carrier` 元数据，三个入口各自打开对应场景。显示和编辑继续使用原有 `carrier_notification_*`、`carrier_control_*`、`carrier_lockscreen_*` 键，不复制参数或丢弃用户保存值。各入口顶部开关对应本场景的启用键，恢复默认仅作用于当前场景；其他长详情的恢复操作只重置当前页，短详情恢复完整功能组。

功能主开关默认关闭，保存过的配置保留并在开机时加载；蜂窝数据箭头始终隐藏。原有设置键继续兼容，新参数按功能分组；搜索覆盖各组和模式相关的设置。底栏使用普通 Miuix 实色导航，弹窗最高层和颜色编辑器接线保留，见 [底栏说明](LIQUID-GLASS-NAVIGATION.zh-CN.md)。

删除所有配置保留免费声明确认、Root请求标识和桌面组件状态，取消待确认试用以免回写；主配置、恢复备份、旧框架镜像和私有导入资源回默认，框架未连接时等待重连同步。用户导出文件不删除。历史观察不替代本轮验证，最终结果见 [VALIDATION.md](../VALIDATION.md)，当前操作见 [code58说明](LOCAL-1.6.1-CODE58.zh-CN.md)。
