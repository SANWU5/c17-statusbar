# 配置分类与详情整理

本文对应正式版 `1.6.0` / versionCode 51。底部导航保留“主页、配置、关于”，使用贴边、无阴影的普通底栏。配置页面按实际使用界面分为四类，搜索覆盖全部分类并定位具体参数。

| 分类 | 入口分组 |
| --- | --- |
| 状态栏 | 时间与电量、网络信号、通知图标与字体 |
| 通知栏 | 时钟与日期、通知显示、通知栏文字 |
| 控制中心 | 磁贴与滑块、音乐卡片、顶部时间与文字 |
| 锁屏 | 锁屏运营商 |

同类入口放在一张列表卡内，短详情直接展开。位置、大小、颜色的启用开关与相应参数放在同一节，不再集中堆在独立开关列表。

四个分类标签使用 Miuix `TabRowWithContour`，均分一行空间，并通过实际文字测量适配字号，用于完整展示“状态栏、通知栏、控制中心、锁屏”。仅分类标签局部调整字号，其他页面文字继续使用系统字号。

状态栏新增“通知图标区域”，主开关默认关闭。显示方式为原生通知图标、单个爱心、自定义符号或文字、自定义图片；模式相关的文字或图片行按当前选择显示，全局搜索仍可直接找到隐藏行。符号或文字最多12个 Unicode 码点，图片支持PNG、JPEG、WebP且最多2MB；未导入图片时保留原生通知图标。导入图片不会自动开启主开关。位置、大小与浅深背景颜色同页设置，图片内部版本号不出现在界面中。

最大显示数量有独立开关，默认关闭，仅原生图标模式生效。手动输入必须为非负整数，可超过滑块建议范围；0 表示不显示图标，不删除或关闭通知。切换到爱心、文字或图片模式后，不应用原生图标数量设置，搜索仍可定位这些参数。

图片导入会保持宽高比，将最长边缩至不超过128px并保存为应用私有 PNG；不长期保留原文件访问权限。导入文件与图片模式、名称、版本配置一起提交，失败时尝试恢复原文件及配置。SystemUI 通过只读接口读取，并校验文件版本；图片尚未加载或校验失败时继续显示原生通知图标。

电池详情增加“电池内文字”一节，独立调整水平与垂直位置、字号、字重和字距，关闭该节开关时恢复原生文字样式。网络文字仅在确认 Wi-Fi 和蜂窝数据开关均关闭时自动隐藏；关闭 Wi-Fi 但蜂窝数据状态未知，或仅未连接网络时，不据此隐藏。

蜂窝详情提供“无网络标识间距”，独立选项默认关闭，间距默认是相对原生的0dp增量。开启蜂窝功能与此选项后，仅在 Wi-Fi 图标和蜂窝网络制式文字均确认未显示、原生最末可见图标是紧邻电池的蜂窝图标时生效。关闭、0dp、状态不明或原生布局不匹配时使用原生间距；这个条件与前述网络开关关闭时隐藏文字的规则分开判断。

字体详情提供 10 种真实可变字体设计，2 种自身覆盖简体中文，其余 8 种拉丁字体使用系统中文回退。这是可选字体目录，不是热门排名。首次选择按需下载，已下载文件经校验后可离线复用；下载取消、失败、应用离开或编辑权限变化时保留原字体。选用字体不自动开启字体主开关，完整来源与许可见 [字体库说明](FONT-CATALOG.zh-CN.md)。

数字参数可手动输入，先试用 20 秒，确认后保存；超时、离开应用或冷启动时恢复原值。滑块范围为建议范围，手动输入可超出建议，但必须是可表示的有限数值，运行时仍进行绘制保护。统一圆角半径硬限制为 0–30dp；原生通知图标最大数量另要求非负整数。配置页不再提供实时预览区域，试用结果以 SystemUI 实际显示为准。

输入弹窗按实际参数显示所属板块、小节、单位、当前值、默认值和建议范围，不将滑块步长当作输入精度限制。通知数量、圆角和所选字体字重各有专门说明；时间格式与普通文字分别提示语法和长度。数值键盘支持小数，可切换科学计数和正负输入。试用确认显示上次确认值与本次输入值，长说明可滚动，确认、保存和取消按钮保留在独立区域。

仅长详情按场景分节：大时钟为时间、日期、通知、动效、底部；电池为样式、布局、电池内文字、颜色；磁贴颜色为浅色、深色界面；音乐卡片为常用、浅色、深色界面。场景切换使用正式 Miuix `TabRow`，不新增多层导航。大时钟原有水平、垂直偏移键在时间页首先展示为“初始位置”；收起样式与收起位置可展开调整。通知堆叠显示“底层bug修复不了 该功能不予适用”，其开关和相关参数不可操作，运行时也保持关闭。

顶部图标切页默认关闭。Phone及控制中心左侧与右侧使用相同的OEM原生交接；通知页实际展开/横切时仅隐藏已识别的旧左侧副本，纵向首尾与完全收起交还原生。大时钟仅在竖屏替代qs_footer_clock，横屏恢复原生时间及普通通知时间配置；关闭、安全模式、锁屏及解绑恢复原生。右侧及其他已通过功能保持，通知堆叠仍不可启用。

音乐背景在最后一次内容或样式变化后等待1.5秒，期间保留旧背景；新背景准备完成后，复用已准备的新旧结果进行轻量透明度过渡，不额外执行模糊。停止播放等内容变化同样经过防抖；关闭功能或安全模式立即恢复原生显示。

关于页保留应用图标、名称和作者aiingjie，提供手动“检查更新”与“正式发布”。更新检测仅使用本项目正式Release，发布和APK链接经本项目HTTPS地址校验后由系统浏览器打开。

通知栏、控制中心、锁屏文字仍共用原有 `carrier` 元数据，三个入口各自打开对应场景。显示和编辑继续使用原有 `carrier_notification_*`、`carrier_control_*`、`carrier_lockscreen_*` 键，不复制参数或丢弃用户保存值。各入口顶部开关对应本场景的启用键，恢复默认仅作用于当前场景；其他长详情的恢复操作只重置当前页，短详情恢复完整功能组。

功能主开关默认关闭，保存过的配置保留并在开机时加载；蜂窝数据箭头始终隐藏。原有设置键继续兼容，新参数按功能分组；搜索覆盖各组和模式相关的设置。底栏使用普通 Miuix 实色导航，弹窗最高层和颜色编辑器接线保留，见 [底栏说明](LIQUID-GLASS-NAVIGATION.zh-CN.md)。

历史版本的观察不替代本版验证；正式构建、桌面检查与本版有限实机范围分别以 [VALIDATION.md](../VALIDATION.md) 为准。参数规则见 [1.6.0 参数说明](PARAMETER-UPGRADE-1.6.0.zh-CN.md)。
