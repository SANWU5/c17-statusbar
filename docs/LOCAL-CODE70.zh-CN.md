# 1.8.1 / code70 本地修复

本次为本地验证包，尚未安装到手机或上传 GitHub。保留已有配置，不进行全量重置。用户反馈的 PLK110 数据仅作为排查条件；原生接口核对使用工作区已有的 ColorOS 17 样本，不能替代该机型的实机验证。

## 改动

- 状态栏时间按 SystemUI 原生像素字号计算，100% 对应原生大小。测量不再依赖可选的 `actualWidth` 字段；比例只应用一次，自定义期间隔离重复自动缩放。时间使用外层实际空间预算，保留通知图标占位，超大文字只裁自己的槽位。
- 旧字号比例携带独立基线标记。有确证的小基线时兼容旧补偿比例；主动编辑采用新基线。导入、导出、20 秒试用及失败回退保留原始元数据，避免换基线时重复放大。
- “文字来源”统一列出系统、苹方、所有导入字体及 10 款开源可变字体。未下载字体可见并标注“需下载”，导入支持多文件保留、重命名、删除。删除当前字体回退系统，失败恢复文件和配置；来源与许可放在页面下方。
- 去除 C17 高光后，五种设备卡片的独立背景采用对应浅色/深色亚克力基色；自定义背景采用用户颜色。保留原生形状、裁剪、交互透明度及自定义磁贴、媒体材质优先级。
- 通知栏竖向展开和收起时，右侧手机状态图标只改变透明度，不写位置；控制中心保留原有过渡。
- 修复磁贴统一圆角与原生按压形变不同步。缺少完整原生接口时保留系统路径。
- 网速水平偏移参与实际占位，Wi-Fi 切换保持同一锚点，可开启周围图标安全间距。单卡制式文字修正为独立水平链路，兼容漫游标识并保留关闭恢复。
- 电池增加隐藏充电图标，隐藏绘制不改真实充电模型。
- “其他”增加流体云展开面强调色；复用原生媒体颜色和背景处理，不增加模糊计算或轮询。异常部分写入后仍可在关闭、安全模式或解绑时恢复。
- “锁屏”增加顶部壁纸区域模糊：强度、遮罩颜色、范围和过渡范围。使用原生背景模糊，跟随系统状态和 AOD；不支持原生接口时回退。

## 实机检查

Debug 编译、Release 构建、`lintVitalRelease`、97 组回归检查通过；最终 APK 的 v2 签名与 16KB 对齐验证通过。时钟专项 10251 项、设备材质 22167 项检查属于代码和契约验证，并不等于实机视觉通过。

1. **时间和通知图标**：先保留旧 380% 打开检查，确认没有突然再次放大；再主动改成 100%、150%、200%。100% 应接近系统原生大小，比例连续变化，左侧通知图标一直保留。快速收起通知栏和控制中心，确认两侧没有额外闪烁。
2. **诊断**：启用日志后，在正常展开和放大时各导出一次。时钟记录包含 `nativePx`、`resourcePx`、`capturedPx`、`appliedPx`、`measuredWidth`、`availableWidth` 和 `legacyFactor`，不记录通知内容或时间文字。
3. **字体**：检查统一列表、需下载提示；导入两款字体并切换，确认前一款仍在。删除当前导入/下载字体应回退系统，其他字体保留。
4. **设备卡片**：分别在浅色、深色检查电脑、耳机和设备入口的底色；开关高光去除及自定义背景，确认原生圆角、图标、按压和关闭恢复正常。自定义磁贴颜色与音乐背景应继续优先。
5. **位置和交互**：反复开关 Wi-Fi，确认网速位置稳定；检查安全间距、单卡制式文字和漫游。长按、点击和编辑磁贴，确认圆角过渡连续。通知栏竖向下拉/收起，右侧只渐隐/渐现且位置不变。
6. **新增效果**：开启充电图标隐藏后接入/断开充电；展开音乐流体云确认强调色。锁屏顶部模糊检查锁屏、解锁和 AOD 的范围与过渡，不应污染时间、图标和整张壁纸。

安装本次包后需要让 SystemUI 加载新注入代码。激活检查使用独立的 code70 标记，旧注入不会被当作新包已生效。不要清空配置来代替验证。

详细接口和兼容说明见 [StatClock](STATCLOCK-NATIVE-PIXELS.zh-CN.md)、[设备卡片](C17-DEVICE-ACRYLIC.zh-CN.md)、[流体云](FLUID-CLOUD-ACCENT.zh-CN.md)。
