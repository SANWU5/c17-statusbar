# 1.6.1 / code58 本地用户说明

本版本尚未上传或公开发布，GitHub 正式下载仍为 [v1.6.0](https://github.com/SANWU5/c17-statusbar/releases/tag/v1.6.0)。最终 Debug/Release 与 lintVital 构建、69组桌面检查及签名/对齐检查通过；最终包已覆盖安装，功能实机验收改由用户反馈。code57 的重启和界面记录不作为 code58 验收。

## 默认值与保存

已保存的功能开关和数值按原值保留。新增功能默认关闭，蜂窝数据箭头始终强制隐藏。新横屏大时钟不会因为竖屏已开启而自动开启；旧“顶部图标切页”已移除入口，运行时强制关闭，不提供固定状态栏副本。

主配置及恢复备份保存在本应用私有设备保护存储，确认成功的完整快照通过官方 libxposed 服务同步到框架。真实编辑仍通知 SystemUI，临时试用不成为开机快照。完整旧 code57 框架快照可按本轮兼容规则补入新增默认值；缺旧项、类型损坏或不完整新项不伪装成完整配置。升级后正常打开应用可同步当前完整设置。

范围内合法手工输入直接保存，**仅建议范围外数值先试用20秒**，确认后保存，取消、超时或离开恢复原值。统一圆角硬限制0–30dp，通知数量必须合法整数；完整通知默认1条，旧保存数量保留，建议1–5，允许更大正整数，但不会生成通知或按输入数量创建巨大列表。

## 竖屏与横屏大时钟

入口：配置 → 通知栏 → 时钟与日期，分别打开竖屏大时钟、横屏大时钟。两页拥有独立开关及对应时间、日期、初始/收起位置、通知留白、顶部边缘与底部文字参数。

横屏采用上方时钟、下方通知列；通知字体、图标及真实卡片高度保持原生，清除按钮位于通知列右侧。通知间距变更同步实际测量和占位，顶部效果可随真实滚动渐隐/模糊，底部自定义文字保持清晰。字体、测量及模糊在实际来源和参数未变时复用。关闭当前方向的大时钟、安全模式、锁屏或解绑时恢复对应原生显示，控制中心仍使用自己的原生时钟。

原生小字号在实际配置来源中捕获 baseline，只应用一次，避免原生测量与模块样式反复缩放。诊断默认关闭，开启后才记录 native/appliedPx 供检查；不同 ROM 的字体及布局行为待验证。

## 两种独立通知堆叠

入口：配置 → 状态栏 → 通知显示。两开关默认关闭，均独立于大时钟，可同时开启。

| 开关 | 处理范围 | 操作 |
| --- | --- | --- |
| 堆叠通知 | 沿用原整体堆叠开关，折叠外层原生通知列表 | 显示最新收到的真实通知及最多三层底沿；轻点展开完整原生列表，收起后重新折叠 |
| 同类通知堆叠 | 系统已有消息组的内部子通知 | 显示组内最新消息和底沿；点击原生卡片展开，长按、滑除继续由系统处理 |

最新依据 StatusBarNotification 的实际收到时间，不依赖应用自填时间，也不简单使用系统优先级排名。不同应用的独立通知不会被合成一组。不删除通知、不改变通知字号和真实高度、不重建假通知；未知原生结构、消息元数据不完整或交互冲突时保留原生行为。快速滑动、展开分组及收起重开仍需本轮设备复核。

## C17 材质与音乐

通知栏和控制中心均有 C17 高光去除入口，默认关闭。处理已识别的 Edge、光学高光、InnerShadow 内缘光泽和 Spotlight，保留模糊、圆角及原生交互；未知材质不广泛替换。

另有默认关闭的“自定义亚克力底色”，分别编辑浅色/深色颜色和透明度。**底色开启时优先于磁贴填色、渐变及音乐封面背景**；如需保留现有封面/磁贴背景，只关闭底色即可继续去高光。关闭功能、安全模式或释放时恢复当前原生材质。

音乐等待最后一次内容/样式变化后1秒，再用160ms淡出旧封面到当前原生高光材质、240ms淡入新封面。过渡复用已准备的封面、模糊与材质，不逐帧重做模糊；无实际变化时使用缓存。桌面缓存计数或视觉观察不能证明设备 GPU、帧率及耗电改善。

## 系统提示与网络

入口：配置 → 状态栏 → 系统提示 → 系统提示图标。主开关默认关闭，控制蓝牙、定位、闹钟等原生提示的水平/垂直位置、最多显示数量、附加间距与优先级。数量默认14、附加间距默认0；中文名称或 ASCII 系统标识可用逗号分隔，页面提供蓝牙、定位隐私、勿扰闹钟等预设。

此功能不控制通知图标、Wi-Fi、蜂窝信号、电池和网速，不扩大网络区域；复杂交错、无法可靠识别的行保留原生。网络信号 → 网络图标顺序为另一个独立默认关闭开关，交换 Wi-Fi / 4G / 5G 与蜂窝信号，保留各自样式、位移、RTL 和系统动画。网速刷新及四种样式继续分别开启，刷新建议1–5秒、实际最低0.5秒。

全部功能永久免费、永不收费，捐赠自愿。微信/支付宝行点击后打开原图弹窗，关于页不铺图。首次免费确认只存应用私有身份，不进入运行配置或导出。

## 应用内更新

关于页检查本项目 HTTPS 正式 Release。已授予 Root 且发现更高版本时，可由用户显式点击应用内更新；不定时静默安装。只接受本仓库正式 APK，下载大小及摘要、包名、版本和当前签名均通过才覆盖安装，结束/失败清除临时 APK。缺少可验证元数据、签名不兼容或无 Root 时不走自动安装，仍可查看项目发布页。

覆盖安装保留应用数据，但新 hooks 仍需重新加载 SystemUI 才生效。显示“模块已启用”与“当前版本已生效”是不同状态，不能将下载或安装完成当作当前 runtime 已重新加载。

## 隐藏与恢复桌面图标

入口位于关于页最底部，默认关闭，无需 Root 或 LSPosed 权限。点击隐藏需确认；操作只禁用本模块 Launcher alias，使用 DONT_KILL_APP，不关闭当前页面、不停用模块及配置。组件状态由 PackageManager 保存，不属于运行配置、导出或“删除所有配置”范围。

隐藏后可从支持模块设置入口的 LSPosed 管理器进入本应用，再关闭隐藏开关恢复图标，启动器可能稍后刷新。模块保留独立 MAIN + `de.robv.android.xposed.category.MODULE_SETTINGS` 设置 alias 和 INFO 回退入口，且不带 LAUNCHER。标准来源为 [官方 AppHelper.getSettingsIntent](https://github.com/LSPosed/LSPosed/blob/master/app/src/main/java/org/lsposed/manager/adapters/AppHelper.java)，管理器[模块菜单调用链](https://github.com/LSPosed/LSPosed/blob/master/app/src/main/java/org/lsposed/manager/ui/fragment/ModulesFragment.java)会查找该入口；当前使用框架上的实机打开仍待复核，不把源码合同当成设备操作验收。
