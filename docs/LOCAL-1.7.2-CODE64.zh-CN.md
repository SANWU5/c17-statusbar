# 1.7.2 修复更新

版本 1.7.2 / versionCode 64，变化对比 [1.7.1](https://github.com/SANWU5/c17-statusbar/releases/tag/v1.7.1)。发布说明见 [RELEASE-1.7.2](RELEASE-1.7.2.zh-CN.md)。

## 本次处理

- 原生单卡蜂窝图标补齐位置、大小调整，资源包装与控件调整分别处理，避免重复位移和缩放；关闭或安全模式恢复原生值。
- 单卡网络文字补齐首次绑定和原生更新回调；在已知主流量卡的当前模型中读取文字，保留无线网络关闭时的隐藏规则，不猜测未知订阅。
- 下拉时钟仍可跟随状态栏时间格式和文字样式，但不再继承主状态栏的位置偏移；独立设置关闭时保留原生页面位置及动画。
- 时钟可选宽度缓存缺失、磁贴抽象回调均做兼容处理；诊断增加单卡绑定数量和实际原生回调次数。

## 检查范围

Debug、Release、lintVital 和 75 组 Release classes 检查通过。包含反馈日志里的密度、蜂窝偏移与网络文字比例，以及重复原生更新、开关恢复和释放时未结束的事务检查。签名与此前版本一致，16KB 对齐通过，Java hooks 保持 Java 8 字节码。

用户要求本次直接发布，未进行手机安装或实机复测。日志能确认参数保存和应用通知成功，不能完整还原反馈机型的实际绘制过程。原始绘制接口依据现有本机 SystemUI；反馈机型的最终视觉效果仍须实际使用确认。

覆盖安装后重启 SystemUI 或手机加载新代码，已有配置保留。
