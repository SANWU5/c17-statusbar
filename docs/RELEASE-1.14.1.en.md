## C17 Status Bar 1.14.1

- Compact home categories, a two-column layout on wider screens and consistent line icons.
- Unified feature switches, numeric inputs and setting layouts, retaining independent section expansion states.
- Grouped HSB color controls with safer card and control spacing.
- Existing status bar configuration is preserved.
- Module source uses GNU GPLv3 (GPL-3.0-only), with the complete license and copyright notice included. Third-party resources retain their own terms.
- The APK includes the complete GPLv3 text and an offline license entry.

**Verification scope:** resource, production Java, DEX and independent source compilation, APK signature/alignment and source archive checks were completed. No check suites or device UI tests were performed in this release cycle.

Install `c17-statusbar-1.14.1.apk` over the same-signed installation, then restart SystemUI. Corresponding source is provided as `c17-statusbar-source-1.14.1.zip`.
