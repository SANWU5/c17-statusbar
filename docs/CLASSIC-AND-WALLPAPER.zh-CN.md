# 经典模式文字与下拉壁纸

本页对应 `1.8.1 / code69`。

## 经典模式文字

入口：**配置 → 通知栏 → 界面文字 → 经典模式文字自定义**。

“运营商”和“时间与日期”分别设置。每个标签页右上角开关只控制当前内容，可调格式、位置、大小、字重、字距及浅色/深色颜色。经典模式设置与分离式通知栏、控制中心的设置独立保存。

模块读取系统实际面板模式。经典模式下暂停横竖屏大时钟、依赖大时钟的堆叠和相关动效，不清除已保存参数；切回分离模式后恢复。读取不到明确模式时保留原生判断，不用默认配置猜测。

## 下拉壁纸

入口：**配置 → 其他 → 下拉背景 → 下拉面板壁纸**。

此功能标注 **“未完成的开发”**，当前版本强制停用，无法开启或导入新图片。旧配置、导入配置和开机恢复均不启用壁纸绘制或后台图片解码。

已保存的经典、分离通知栏、分离控制中心横竖屏参数和图片继续保留。“一键删除所有配置”及正常卸载仍会清理应用私有图片；用户导出的文件不删除。后续继续完善图片背景与模糊过渡后再开放。
