> **code99 更新（本页下面“实现”“检查”两节描述的是 code96～98 的做法，已被取代）**：需要任何外观时，胶囊背景换成我们自己的 `PillBackground`（实心、从上到下、从下到上、径向），不再改插件的 `GradientDrawable`，所以渐变关闭后不会有残留（code98 的旧渐变着色器留在画笔里，是“关了渐变还在生效”的原因）；同类的底色变化（关掉媒体后跟随色换成自定义色、切歌）有 0.6 秒的渐变过渡；插件自己的淡边在有跑马灯、自定义边框或自定义圆角时换成叠加层里的一个“环”，环不存在时用最后一个展开进度再调一次插件自己的展开步骤恢复。背景模糊现在是一个平台模糊区域，**由背景自己最先画**，带“遮罩颜色”，开启后自定义底色、渐变、跟随媒体色置灰且不再起作用；跑马灯预设 22 个，自定义 2～6 色，“向内渐隐”是一整片细而密的同心圈；频谱的识别增加了 JSON 文本和已加载动画两种方式，可自定义颜色、可跟随强调色，条高按每个频段自己最近的响度范围算，灵敏度整个 0～100 都起作用。圆角范围仍是 0～15dp，但现在由我们自己的背景和外框画。详见 [LOCAL-CODE99](LOCAL-CODE99.zh-CN.md)。

> **code98 更新**：摄像头区域流体云新增渐变底色（从上到下、从下到上、中间向四周）、背景模糊、边框跑马灯（彩虹、霓虹、极光、火焰、冰川、单色流光、自定义，可调透明度、转一圈用时、方向）和实时频谱；**圆角半径改成 0～15dp，默认 15**：胶囊约 30dp 高，原生 20dp 已经大于半高、本来就是完整胶囊，所以以前把半径调大看不出变化，只有调小才会变方。渐变用 `GradientDrawable` 自己的渐变；跑马灯是胶囊 `ViewOverlay` 里的一个旋转扫描渐变描边（约每秒 30 帧、只在显示时画）；背景模糊用系统窗口背景模糊（`ViewRootImpl.createBackgroundBlurDrawable`，反射），只有底色透明度调低时才看得见，不支持时没有效果。实时频谱见 [LOCAL-CODE98](LOCAL-CODE98.zh-CN.md)。

# 摄像头区域流体云（胶囊）自定义

code96 新增。“设置 → 其他 → 流体云 → 摄像头区域流体云”。

## 它改什么、不改什么

摄像头周围的流体云叫“胶囊”（Seedling capsule）：音乐、计时、来电等收起或展开时，围着前置摄像头出现的一颗黑色胶囊。它在 `SystemUIPlugin.apk` 里是 `com.oplus.systemui.plugins.seedling.capsule.ui.view.CapsuleView`：一个 `FrameLayout`，**背景**是黑色圆角矩形（`capsule_background_color`，20 dp），**前景**是一层透明的外框（1.3 dp、25% 灰色的描边，同样 20 dp 圆角）。展开过程中，插件每一步都会重写外框的描边（收起时有、展开后没有）。

本页只改这两个 `GradientDrawable` 的三样东西：

| 设置 | 作用 | 默认 |
|------|------|------|
| 自定义底色 + 底色 + 底色透明度 | 胶囊的填充色 | 关（原生黑色） |
| 跟随媒体强调色 | 有媒体时用当前媒体色，并叠加“流体云媒体强调色”页的遮罩；透明度用本页的“底色透明度” | 关 |
| 自定义边框 + 边框颜色 + 边框粗细 | 外框的描边。自定义的边框**始终显示**（原生只在收起时有一圈很淡的边） | 关 |
| 自定义圆角 + 圆角半径 | 底色与外框共用同一个半径（0～40 dp） | 关（原生 20 dp） |

不改：胶囊的位置、大小、内容（图标、文字、头像）、动画、摄像头孔位。胶囊里的文字和图标仍是插件自己的颜色（白色为主），**底色选得很浅时文字会不易看清**，请选深色或半透明。

## 与其他流体云功能的关系

- 总开关关闭时一切恢复原生；任何单项开关关闭，该项恢复原生。
- “跟随媒体强调色”读的是流体云媒体强调色页同一份媒体色（`FluidCloudAccent.nativeCurrentMediaColor` + `maskedMediaColor`），但**不依赖**那一页的总开关；没有媒体时用自定义底色，两者都没有就是原生黑色。
- 与 C17 高光去除、流体云样式页的卡片底色、作用场景开关互不影响：胶囊不是通知卡片。

## 实现

`FluidCloudCapsule`（运行时）、`StatusBarModule.installFluidCapsule`（在插件类加载器出现时安装钩子，和流体云强调色同一个入口）。

- **结构校验而不是名字**：插件是混淆过的，`CapsuleView` 的成员大多是 `a`/`b`/`c`。运行时检查它是 `FrameLayout`、有且只有一个 `GradientDrawable` 字段、有且只有一个 `(float)void` 方法（展开步骤）、并有 `onFinishInflate`/`onAttachedToWindow`/`setHidden(boolean)`/`onDraw(Canvas)`；任何一条不满足就不安装，胶囊保持原生。
- 钩子都在原生代码**之后**运行（`onDraw` 在之前做一次轻量比较）：膨胀后、挂载后、隐藏/显示后、每次展开步骤后，把设置重新写到背景与前景上。展开步骤会重写描边，所以自定义描边在每一步之后再写一遍。
- **恢复**：第一次接触一个胶囊时记下插件原来的填充色（`ColorStateList`）和两个圆角；关闭时按记录恢复；描边的恢复是用记下的最后一个展开进度再调用一次插件自己的展开步骤，得到插件原来的描边。
- 设置变化时，已经在屏幕上的胶囊立即更新；媒体色变化时下一次绘制更新（用 `colorRevision` 比较，不每帧重算）。
- 安全模式等同关闭。

## 检查

`FluidCloudCapsuleCheck`（77 项）：默认值与目录、按开关逐级灰显；结构校验；自定义底色（含颜色自带透明度与“透明度”的合成）、边框（插件重写描边后再写回）、圆角（背景与外框同一半径）；跟随媒体色；全部关闭后填充、圆角、描边（含展开状态下的描边）恢复原样；安全模式；意外的 Drawable 不被替换；释放后不再着色。桌面检查用的是按审计结构写的桩类，**没有在手机上跑过**。

## 尚未在手机上验证

- 胶囊在真机上的实际外观：不同阶段（收起、展开、来电、计时、音乐）是否都被覆盖；展开动画中描边是否有一帧闪回原样。
- 带平滑圆角（`smoothG2`）的圆角在自定义半径时是否保持平滑。
- 跟随媒体色在音乐切歌时的更新是否及时。
