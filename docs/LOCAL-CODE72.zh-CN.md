# 1.8.1 / code72 本地修复

本轮仅处理时间省略号和锁屏顶部模糊层级。用户最后指定重新连接后只读取数据；手机已读取配置、原生布局、framework 和壁纸窗口信息，没有切页、旋转、改配置、安装或重启。没有上传 GitHub 或发送私人数据。

## 时间被显示为省略号

code71 在通知宽度已分配后仍累计全部通知子项。原生容器的 HIDDEN 项保持 Java VISIBLE，旧预算会错误放大占位，把时间挤窄。新代码使用容器当前正测量宽度；零宽时按原生数量上限、ICON/DOT/HIDDEN 与 padding 保守恢复。未知状态回退原生约束。

本机只读数据中原生时间文本完整，通知容器实际230px、原生上限3，有大量 HIDDEN 项。采集时手机在横屏全屏应用，不能声称已现场复现竖屏省略号。修复路径已通过匹配原生结构的检查，实际效果仍待用户确认。

保留用户现有字体、大小、偏移和旧比例兼容，不关闭省略号来掩盖布局问题。完整字宽纳入 compound padding。诊断增加 desiredWidth 与 widthLimited，仍只记录字号、宽度等数值，不记录时间文字或通知内容。详见 [StatClock说明](STATCLOCK-NATIVE-PIXELS.zh-CN.md)。

## 锁屏模糊只覆盖壁纸

取消 Keyguard/AOD/通知窗口里的模糊和颜色遮罩绘制。新增自有 SurfaceControl 子树，仅挂在原生锁屏壁纸窗口内、位于所有前景组件之下；使用独立透明模糊与颜色层，跟随原生 doze/scrim/dismiss。

原生冻结前同步排除自有效果，结束后重设真实快照锚点；关闭、退休和 native surface 销毁只移除自有层。相同状态不重复提交事务，没有新增截图请求、CPU 模糊或轮询。

支持本机已核对的静态 ImageWallpaper 默认屏、一比一全屏映射。外部动态壁纸或未知缩放保留系统画面；旋转过渡尺寸未就绪时临时隐藏，之后恢复。详见 [壁纸层级说明](LOCKSCREEN-BLUR-DIMMING.md)。
