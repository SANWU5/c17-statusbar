# C17 临时卡片验证

本地临时验证包，版本 1.0.0，ID `dev.c17.validation.qs-card`，需要 **Status C17 2.0.3 / code195**。API 1 的 `settings` 是唯一能力；没有 SystemUI 方法规则、Java/Android 桥或原生代码。源码仅在本项目的检查 fixture 中，不内置到 App，不收录到公开目录，不通过本轮上传到任何仓库。

在扩展插件的“导入”页选择本包，查看来源、能力与规范后确认安装。安装默认停用；启用后在插件表单选择验证模式。默认“恢复本次实验原生”会临时关闭本次五个开关，其他模式分别启用大音乐、六行、原生卡片拖拽、无媒体隐藏、卡片壁纸、六行＋大音乐或综合。每次切换都会明确设置全部五个开关，避免上一模式残留。

插件不改写用户保存的主设置，不更改其他功能、壁纸引用、透明度、媒体数据或系统保存的卡片跨度。停用或删除插件后恢复用户原本保存的五项设置；因此如果用户原本已启用某项，停用插件会恢复该选择。安全模式跳过插件覆盖。验证结束后停用并删除此包。

“卡片壁纸”只打开显示开关，使用用户此前在本机选择的图片；没有有效图片时保持原生背景，不会附带、下载或替换图片。暂停播放属于有媒体内容；“无媒体隐藏”不应隐藏暂停时的播放操作。

自动检查只能证明包的导入、能力/设置语义、模式切换和覆盖撤销。当前 ROM 的真实卡片几何、编辑拖拽、系统保存数据是否保持及视觉恢复，仍须按宿主审阅清单验证；不能将导入成功或桌面检查通过写成插件已在手机适配通过。旧宿主可能拒绝这些尚未开放的键，不应绕过校验安装。
