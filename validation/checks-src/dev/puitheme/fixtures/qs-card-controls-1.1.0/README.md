# 控制中心扩展 1.1.0

本包供作者审阅完整插件配置，不随 App 内置，不在公开目录分发。需要 Status C17 2.0.4 / code196、插件 API 1；界面使用宿主原生配置控件，不运行任意 Android 或 Java 代码。

## 八项独立配置

| 配置 | 默认值 | 作用 |
|---|---|---|
| 顶部空间 | 4列×4行 | 选择4、5、6或7行，保留单元高度，空间不足时保留原生 |
| 大音乐 | 关闭 | 已适配音乐卡片显示为4列×2行 |
| 原生卡片调整 | 关闭 | 允许已适配卡片拖拽调整至4×2，未知外部插件保留原尺寸 |
| 顶部小磁贴 | 关闭 | 在已适配的竖屏控制中心使用2列×1行小磁贴 |
| 无媒体隐藏 | 关闭 | 没有媒体数据时隐藏内容控件，暂停媒体仍显示 |
| 音乐卡片壁纸 | 关闭 | 使用宿主已选择的音乐卡片图片 |
| 底部普通磁贴区域 | 始终显示 | 可选始终显示、始终隐藏、下滑展开/上滑收起 |
| 壁纸不透明度 | 100% | 0至100%，仅调整音乐卡片图片 |

布局和下滑显示适用于完成适配的竖屏控制中心。下滑模式进入时底部普通磁贴默认隐藏；在控制中心空白处再次下滑展开、上滑收起，编辑布局时显示可添加磁贴。横屏、未知结构或适配失败保留原生，不能把配置导入成功等同于这些手势已实机验证。

图片通过插件详情关联的“音乐卡片壁纸”入口在宿主中选择或更换。包中没有图片，不读取或写入图片版本标识；未选图片或图片不可用时保留原生背景。

## 导入、更新与恢复

导入 ZIP 并确认后，在“插件”页打开“查看与设置”，逐项配置并手动启用。安装或升级默认停用。本包沿用旧“C17 临时卡片验证”的标识 `dev.c17.validation.qs-card`，版本号由1升级到2。旧包唯一的 `mode` 是临时预设，升级后移除该项，八项配置使用上述默认值，需重新逐项选择；不会把旧“综合”等预设自动转换为长期启用。已有宿主设置与图片保留。后续升级保留仍符合约束的独立配置。

仅在运行副本中覆盖上述八项设置，不写入用户原设置、系统卡片几何、Room数据库、系统备份或安全模式。停用或删除后撤销覆盖，恢复原有设置；安全模式暂停插件覆盖。“恢复默认配置”一次恢复本插件八项默认值，保留当前启用/停用状态，不重置宿主原设置。

与另一个已启用插件覆盖相同设置时拒绝启用或配置更新；旧六行开关与新行数也按同一目标检查冲突。希望直接使用宿主设置时请先停用本插件，避免启用中的插件再次覆盖宿主选择。

真实插件引擎、ZIP导入、保存重开、八项默认恢复、旧八种mode升级、覆盖撤销和安全模式由本地集成检查覆盖。它不证明 PLK110、PJZ110 或其他目标 ROM 的布局、拖拽、下滑、壁纸与停用恢复已经实机验收；这些效果由宿主底层适配实现，需作者逐项审阅。本包不修复锁屏图标，也不引入系统尺寸持久化格式。
