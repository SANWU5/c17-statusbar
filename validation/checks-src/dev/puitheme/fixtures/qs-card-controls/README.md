# 控制中心自由编辑 1.2.1

本包供作者审阅完整插件配置，不随 App 内置，不在公开目录分发。最低需要 Status C17 2.0.6 / code198、插件 API 1；界面使用宿主原生配置控件，不运行任意 Android 或 Java 代码。code197 试验宿主在实机编辑前尺寸查询中暴露了扩展索引进入原生网格的风险，code198 补齐查询来源与范围保护；本包不面向 code197 启用。最低宿主由此说明和插件首行提示告知，API 1 尚不提供独立的最低版本拦截字段。

## 八项独立配置

| 配置 | 默认值 | 作用 |
|---|---|---|
| 顶部自由编辑空间 | 4列×4行 | 选择4、5、6或7行，保留单元高度，空间不足时保留原生 |
| 音乐卡片拖拽调整 | 关闭 | 开启仅允许在系统编辑中手动拖为4×2，不自动改变当前尺寸 |
| 原生卡片调整 | 关闭 | 兼容已适配的音乐卡片与大卡，可在系统编辑中拖至4×2，未适配卡片保留原尺寸 |
| 顶部小磁贴 | 关闭 | 在已适配的竖屏控制中心使用2列×1行普通小磁贴 |
| 无媒体隐藏 | 关闭 | 没有媒体数据时隐藏内容控件，暂停媒体仍显示 |
| 音乐卡片壁纸 | 关闭 | 使用宿主已选择的音乐卡片图片 |
| 更多磁贴 | 更多磁贴入口 | 可选始终显示、隐藏、更多磁贴入口 |
| 壁纸不透明度 | 100% | 0至100%，仅调整音乐卡片图片 |

自由编辑仅适用于完成适配的竖屏控制中心。“更多磁贴入口”会在顶部放置一个可排序的入口磁贴，点击后打开更多磁贴专页；返回回到顶部，上划收起控制中心后再次下拉也回到顶部。它可以独立开启，无需同时开启顶部小磁贴，不再通过空白处下滑来显示列表。“始终显示”保留普通磁贴列表，“隐藏”隐藏该区域。

音乐调整开关只开放编辑能力，开启后保持当前尺寸；需要进入系统编辑，自己拖为4列×2行。原生卡片调整同样兼容已适配音乐卡片，不要求同时开启两个开关。当前包不承诺2×1或4×1音乐模板，后续支持应以宿主真实能力为准。横屏、未知结构或适配失败保留原生，配置导入通过不等于专页、拖拽或恢复效果已经实机验收。

图片通过插件详情关联的音乐卡片壁纸入口在宿主中选择或更换。包中没有图片，不读写图片版本标识；未选图片或图片不可用时保留原生背景。

## 导入、更新与恢复

导入 ZIP 并确认后，在插件页打开查看与设置，逐项配置并手动启用。安装或升级默认停用。本包沿用标识 `dev.c17.validation.qs-card`，当前 `versionCode:5`。

从自由编辑版1.2.0 / versionCode4更新时，八项仍符合控件约束的配置原样保留，包括 `always/hidden/more` 显示模式；升级后默认停用，需要在 code198 或更新宿主上手动重新启用。

从完整配置版1.1.0 / versionCode2或1.1.1 / versionCode3更新时，原有行数、五个开关和壁纸不透明度等七项有效值保留。显示模式原为 `always` 或 `hidden` 时保持原值，旧 `swipe` 转为 `more`，改用顶部更多磁贴入口；不增加隐藏状态、不丢弃其他参数。升级后需手动重新启用，音乐调整只开放手动拖拽，不自动放大。

从临时验证版1.0.0 / versionCode1更新时，旧 `mode` 是临时预设，与八项独立配置不对应，移除后使用上述默认值并需逐项设置。不会把旧综合预设自动变成长期启用。所有更新保留已有宿主设置与图片；后续更新继续保留符合新控件约束的状态。

仅在运行副本覆盖上述八项设置，不写用户原设置、系统卡片几何、Room数据库、系统备份或安全模式。停用或删除撤销覆盖，安全模式暂停插件效果；原生回退由宿主负责。恢复默认配置一次恢复本插件的八项默认值并保留启用/停用状态，不重置宿主原设置。

与另一个已启用插件覆盖同一设置时拒绝启用或配置更新，旧六行开关与新行数也按同一目标检查冲突。希望直接使用宿主配置时请先停用本插件，避免插件再次覆盖宿主选择。
