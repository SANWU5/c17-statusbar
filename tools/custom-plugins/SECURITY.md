# 安全政策

## 报告渠道

涉及隔离绕过、恶意插件、供应链问题、凭据或用户数据泄露时，请使用本仓库的 [GitHub 私密漏洞报告](https://github.com/SANWU5/c17-plugins/security/advisories/new)。如果该入口暂不可用，请向仓库维护者发送可用的 GitHub 私密联系请求，或开一个仅写「请求私密安全报告渠道」的 Issue；在获得私密渠道前不要贴利用代码、日志、凭据或用户数据。不要把安全详情放进普通公开问题单。

报告请给出宿主/API/插件版本、ROM 信息、影响范围、最小复现、你观察到的行为和可选修复建议。移除账号、令牌、设备标识、通知内容及其他人的数据；不要为了演示而攻击真实用户、第三方设备或在线服务。

## 处理原则

维护者先确认可复现范围，再协调修复、目录撤回和必要的公开说明。未修复前请避免公开可直接造成损害的利用细节。当前不提供固定响应期限、服务等级或漏洞赏金承诺；紧急问题应先在设备上停用相关插件并使用恢复机制。

本仓库不能远程停用已安装插件。修复版本使用更大的 versionCode，更新安装仍默认关闭；目录会移除已知问题包或添加更新说明，用户需要自行确认和处理。

## 禁止行为

禁止窃密、植入后门、隐蔽联网或跟踪、破坏设备和数据、绕过沙箱、发布盗用内容、替换同版本文件、投毒依赖、欺骗授权或用混淆隐藏恶意行为。发现这类问题可导致撤回和停止接受贡献；必要时保留脱敏证据供调查。
