# 时钟垂直间距开发模板

仅供开发者阅读、复制和改写；不列入公开插件目录，不代表目标 ROM 已完成适配。使用本模板源码遵循仓库 MIT 许可；正式插件应单独声明作者、来源、许可、适配和恢复方法。

在已核验的 `Clock.updateClock()` 后临时设置该 View 的 `translationY`，单位由宿主从 dp 转换成 px。示例表单收窄到 -12–12dp，默认 0。规则本身允许 ±200dp，但不建议在状态栏使用大幅偏移。

目标类/方法与 text-fix 一样需要在实际 ROM 核验；这不是通用布局修复。它更改绘制位移，不改变测量高度。不要同时启用多个针对同一属性的插件或与原生位置调整叠加猜测结果。未进行手机验收。

本模板保留旧 API 1 字段和原最低宿主。需要 code210 的详情分组时，参考 [SDK](../../docs/SDK.zh-CN.md#详情与宿主能力声明)：使用段解释 ROM 条件、声明 SystemUI 作用域；功能段保留位移参数；管理段放恢复、更新与删除。声明作用域不是已勾选证明，框架状态无法读取时必须显示未知。
