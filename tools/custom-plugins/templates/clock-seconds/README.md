# 时钟秒数与字号开发模板

仅供开发者阅读、复制和改写；不列入公开插件目录，不代表目标 ROM 已完成适配。使用本模板源码遵循仓库 MIT 许可；正式插件应单独声明作者、来源、许可、适配和恢复方法。

使用 C17 已有的默认状态栏时钟设置，不依赖额外 ROM 类名。独立表单控制秒数和 25–250% 字号比例，主设置只做运行时覆盖。停用、删除或安全模式后恢复用户原设置。

如果已启用双排时钟，它有自己的格式与字号规则。本例不擅自关闭双排。与其他覆盖相同 clock 设置的插件不能同时启用。

本模板保留旧 API 1 字段，不因三段详情更新提高原最低宿主。支持 code210 新契约的开发版本可参考 [SDK](../../docs/SDK.zh-CN.md#详情与宿主能力声明) 加入使用说明、SystemUI 作用域及功能/管理分组；真实框架勾选状态由宿主读取，未知时明确未知。全部秒数与字号参数仍应放在功能段，恢复、更新和删除放在管理段。
