# 更好的 C17 状态栏 · 1.8.1

面向 ColorOS 17 的 SystemUI 定制模块，主要适配依据为 OnePlus 13。使用 LibXposed API 101，包名为 `dev.puitheme.iosstatusbar`。

**1.8.1 / versionCode 69。** 安装包通过 [GitHub Releases](https://github.com/SANWU5/c17-statusbar/releases) 获取。本版新增系统图标库、经典模式文字自定义和双角标独立设置，修复尺寸基准与时钟高度变化问题。对比 1.7.2 的变化见 [1.8.1 发布说明](docs/RELEASE-1.8.1.zh-CN.md)，检查范围见 [验证记录](VALIDATION.md)。

[自定义系统图标](docs/ICON-PACKS.zh-CN.md)支持逐项替换与图标库管理；[经典模式文字](docs/CLASSIC-AND-WALLPAPER.zh-CN.md)有独立入口。下拉面板自定义壁纸暂时强制停用，标注“未完成的开发”，原有图片和设置保留。[图标包规范与示例](https://github.com/SANWU5/c17-icon-packs)在独立仓库维护。

## 功能

- **状态栏**：时间、电池、Wi-Fi、蜂窝信号、网络文字、通知图标和字体分别设置；支持 Wi-Fi / 4G / 5G 与蜂窝信号互换位置。通知图标间距可独立调节，不改变图标大小。原生网络角标分为“角标1”“角标2”，对应原生文字前、后两段，各自隐藏、选择字体、调整位置、大小和字重；仅在自定义网络制式文字关闭时生效。选择主信号单排后只保留当前主流量卡信号，支持独立双卡布局，不依赖仿 iOS 图标样式开关；主卡信息暂未就绪时保留原生显示。
- **系统提示图标**：蓝牙、定位、闹钟等提示可调整水平/垂直位置、数量和间距，并拖拽中文名称设置显示优先级；保留系统当前允许显示的提示，不改网络和电池区域。
- **图标库**：在电池、Wi-Fi、蜂窝信号页面进入“自定义图标”，逐个指定替换图案。其他系统提示可在“其他 → 自定义系统图标”设置。支持 ZIP、RAR、GitHub 导入，以及从用户提供的 PUI 主题导入实际图案；导入库可排序、重命名、删除和禁用。
- **网速与数据箭头**：网速保留原生数字和单位，刷新间隔以毫秒设置，建议 1–500 ms。蜂窝数据小箭头默认隐藏，可单独开启并调整位置、大小和浅色/深色颜色。
- **通知栏**：横竖屏大时钟独立设置。横屏采用上时钟、下通知布局，只用一个字体高度；竖屏原生字体可分别设置展开、收起字高，并通过“屏幕内间距设置”限制左右留白，手势改变字形高度时保持宽度稳定；其他字体只调一个高度。通知宽度可调，保持原生通知字号和图标尺寸。横屏清除按钮有独立位置和颜色设置。整页堆叠使用原生滑动展开、缩放，完整通知数量建议 1–5；横屏须另开“横屏也生效”，默认关闭。同类通知堆叠入口已隐藏，运行时强制关闭。
- **控制中心与材质**：统一圆角、1×1 磁贴及已识别设备卡图标大小、磁贴填色、音乐封面背景。C17 高光去除可分别作用于通知栏和控制中心，支持浅色/深色亚克力底色与统一通知颜色，保留磁贴自定义填色和音乐背景。音乐换封面先显示新封面取样纯色，再淡入后台准备的模糊背景；未变化的结果复用缓存。
- **锁屏**：日期格式支持年月日、星期；小锁可仅隐藏视觉图标，保留解锁和指纹交互。日期处理兼容系统动态加载的锁屏时钟组件。

[字体库](docs/FONT-CATALOG.zh-CN.md) 提供 10 种可变字体设计及来源、许可说明。部分字体使用系统中文回退；字体按需下载，也可导入自选字体。

## 配置与维护

主页、配置、关于使用普通底栏，背景覆盖系统手势区域。配置按状态栏、通知栏、控制中心、锁屏和其他分类；不提供实时预览。隐藏桌面图标位于**主页最下方**，关闭图标后可从支持模块设置入口的 LSPosed 管理器进入并恢复。

功能主开关默认关闭，明确保存的配置保留。滑块给出建议范围，合法手工输入在范围内直接保存；**只有超出建议范围的数值才进入 20 秒确认试用**，取消或超时恢复原值。统一圆角硬限制为 0–30dp。较短网速间隔、磁贴渐变和复杂动效会增加开销，按需要开启。

开机读取框架完整快照和应用提供的配置；数据不完整、临时不可读或写入失败时保留上次确认配置并重试，未确认的试用不会作为开机配置。授予 Root 后可在 LSPosed 未激活时保存配置；安全模式暂停修改并保留参数。

关于页支持诊断报告导出、清空历史日志和一键删除所有配置。删除配置需确认，同时清理恢复副本及私有导入资源；用户自行导出的文件不删除。Root 已授权且检测到本项目新版时，可点击应用内更新，经包名、版本、签名和文件校验后安装，结束或失败后删除临时 APK。正常卸载清理应用私有数据；共享 LSPosed 日志不属于本应用。

## 安装

从 [GitHub Releases](https://github.com/SANWU5/c17-statusbar/releases) 获取已发布安装包。更新前导出需要保留的配置；同签名覆盖安装后，在 LSPosed 中启用模块并勾选 SystemUI，重启系统界面或手机以加载新代码。日常参数修改会通知 SystemUI，无需每次重启。

旧签名安装的兼容路径见 [参数与升级说明](docs/PARAMETER-UPGRADE-1.6.0.zh-CN.md)。Android 26/27 的旧签名覆盖安装不保证兼容。构建检查、实机观察和其他 ROM 的适配范围分别记录，不将桌面检查视作全部实机通过。
