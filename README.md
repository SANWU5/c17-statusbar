## 本版变化

设置页使用与 LSPosed 管理器相同的 Miuix 组件体系，三个普通底栏入口为主页、配置、关于。底栏贴近系统导航区域，取消悬浮留白与阴影；液态玻璃实现已移除。配置按状态栏、通知栏、控制中心、锁屏整理，四个名称完整显示。弹窗位于导航上方，配置页已移除实时预览区域。

手动输入的数值先试用 20 秒，确认后保存；超时、离开应用或冷启动恢复时回滚原值。滑块提供建议范围，手动输入允许超出建议的有限数值，运行时仍保留绘制保护。统一圆角是例外，半径硬限制为 0–30dp，作用于磁贴、音乐、亮度、音量和设备卡片。同一个值采用一致的实际像素半径与原生连续圆角参数，按各控件真实边界限制，保留滑块按压形变、材质和点击范围。1×1图标大小同时覆盖普通磁贴及已识别的方形设备卡主图标、设备空间入口，保留设备电量环；横向多设备卡保持原生。

顶部图标切页默认关闭。Phone及控制中心左侧与右侧使用相同的OEM原生交接；通知页实际展开/横切时仅隐藏已识别的旧左侧副本，纵向首尾与完全收起交还原生。大时钟仅在竖屏替代qs_footer_clock，横屏恢复原生时间及普通通知时间配置；关闭、安全模式、锁屏及解绑恢复原生。右侧及其他已通过功能保持，通知堆叠仍不可启用。

电池内文字可独立调整水平与垂直位置、字号、字重和字距。网络文字在确认 Wi-Fi 与蜂窝数据开关均关闭时自动隐藏；读取状态不明时不据此隐藏。通知图标支持原生图标、单个爱心、自定义文字或图片；最大显示数量有独立开关，仅原生图标模式生效，接受非负整数，0 表示不显示，不删除通知。PNG、JPEG、WebP 最多 2MB，导入后自动归一至最多128像素，保存于应用私有目录。

蜂窝详情新增默认关闭的“无网络标识间距”，默认增量为0dp。仅在 Wi-Fi 图标与蜂窝网络制式文字均确认未显示、原生最末可见图标为紧邻电池的蜂窝图标时，相对原生调整这处边界的间距；兼容 RTL，条件不明或关闭时保留原生间距。它按实际标识显示状态判断，不把未连接网络或开关关闭直接等同于条件满足。

字体库提供 10 种真实可变字体设计，其中 2 种自身支持简体中文，8 种拉丁字体使用系统中文回退。这是可选目录，不是热门排名。字体按需下载并校验来源、大小、SHA256 与真实字重轴；取消、失败或生命周期变化保留原字体。完整来源与许可见 [字体库说明](docs/FONT-CATALOG.zh-CN.md)，图片与字体文件不嵌入配置 JSON。

系统字体的粗细调节直接作用于实际字重轴，保留其他字体轴与原生斜体，关闭后恢复原生设置。音乐背景在最后一次内容或样式变化后等待 1.5 秒，期间保留上一次背景；新背景准备完成后，新旧结果通过轻量透明度过渡切换。过渡复用已准备的背景，不额外执行模糊，不变内容继续复用模糊与材质结果。

除蜂窝数据箭头始终隐藏外，新安装的功能默认关闭；明确保存的开关和参数保留，开机自动加载。授予 Root 后允许未激活 LSPosed 时修改配置，安全模式恢复原生显示而保留用户配置。正常卸载清除本应用的配置与日志，不恢复云端/迁移备份，SystemUI 内存中仍加载的模块也释放样式。

## 使用与构建

显示版本按本次要求调整为1.6.0，Android安装版本号仍递增至51。旧版仅比较显示版本，可能不提示本次升级；请从[v1.6.0发布页](https://github.com/SANWU5/c17-statusbar/releases/tag/v1.6.0)手动下载覆盖安装。

同签名覆盖安装后，在 LSPosed 中启用模块并选中 SystemUI，重启系统界面以加载新代码。日常参数修改会即时通知作用域应用。“关于”页恢复手动“检查更新”，从本项目 GitHub 正式 Release 检测版本；只接受本项目的 HTTPS 发布与 APK 链接，通过系统浏览器查看或下载。

若覆盖安装提示签名不兼容，Android 28及以上的旧签名用户可先覆盖安装既有正式 [1.15.0](https://github.com/SANWU5/c17-statusbar/releases/tag/v1.15.0)，再覆盖安装1.6.0，无需卸载。该路径有签名验证兼容证据，未作为旧签名实机迁移测试；Android 26/27旧签名覆盖不保证，详见 [参数与升级说明](docs/PARAMETER-UPGRADE-1.6.0.zh-CN.md)。

构建使用 JDK 17、Gradle wrapper、Android SDK 37、AGP 9.4.1、Kotlin/Compose 2.4.20 与 Miuix 0.9.4；Java hooks 保持 Java 8 字节码，Compose Kotlin 为 JVM 11，minSdk26/targetSdk35。Windows 可使用 `tools/Build-Compose.ps1`，具体见 [构建说明](docs/COMPOSE-BUILD.zh-CN.md)。

生产源码、公开资源、许可与检查源码可以公开。签名私钥、手机截图、录屏、原始 SystemUI、私人配置与日志不进入仓库。构建、回归检查与实机观察分别记录，不把桌面检查当作实机通过；完整变化、验证范围和第三方版权见 [更新记录](CHANGELOG.md)、[验证记录](VALIDATION.md)、[第三方声明](THIRD_PARTY_NOTICES.md)。
