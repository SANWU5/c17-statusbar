## 本版更新

- 磁贴翻页默认使用左右边缘渐隐，保留系统原本的滑动。效果范围以磁贴页面的实际内边距为准，避免越界覆盖亮度、音量等相邻控件；页面顶部和中间不会额外叠加整层透明衰减。横屏、竖屏独立启停，已有范围及位置配置继续保留。高级模糊选项仍可单独开启，默认关闭。
- 新增全局磁贴活动填充调色：浅色、深色主题分别设置颜色、透明度及渐变，统一应用于支持的 Wi-Fi 内部圆形、音量／亮度已填充部分及其他活动磁贴。保留原生外层玻璃、边框、高光、图标文字及滑动动画。调色默认关闭，关闭后由系统原生绘制。
- 新增配置导出／导入。通过系统文件界面保存或选择 JSON，导入前先检查格式、版本及各项数值，再由用户确认覆盖文件中对应的设置。字体文件、日志、调试开关及本机文件信息不随配置传输；导入配置需要自选字体而本机尚未导入时回退到系统字体。
- 修复隐藏 Wi-Fi 角标和上传下载箭头后，装饰控件仍参与测量导致图标位置跳动的问题。断网、飞行模式间距及系统本身的图标显示语义继续按原生状态变化；关闭隐藏开关时恢复系统最新请求的显示状态。

## 状态栏调节

实时网速、蜂窝信号、Wi-Fi、数据制式文字、时间、运营商文字、字体、电池及磁贴翻页分别拥有独立开关。支持单排真实信号，5G／4G／3G 制式文字归一化；`0.00 KB/s` 实时网速保留，系统角标及上传下载箭头可单独隐藏。

通知页、控制中心与锁屏的运营商内容分别配置为原样显示、时间格式或纯文本，各自拥有位置、大小、字重、字距、浅色／深色颜色和透明度设置。锁屏自定义默认关闭。时间格式支持年月日、星期及上午／下午等内容，并可调整位置和大小。

数值保留两位小数，可点击直接输入。滑条提供建议范围；手动输入超出建议范围的有限数值时，须在 10 秒内选择“是”才保存，选择“否”、返回或超时均取消。位置和字距支持正负值，大小及持续时间等使用非负值；字重遵循 100–900。绘制安全限制不会改写已保存的数值。

磁贴渐隐的左／右范围、各侧水平偏移、垂直偏移、覆盖高度及上下柔化范围均可调整；覆盖高度为 0 时使用页面高度，某侧范围为 0 时关闭该侧效果。高级模糊另有半径及强度调节，依赖 Android 12 及以上硬件绘制，不支持时回退渐隐或原生绘制。

## 电池、颜色与字体

默认横向电池矢量来自用户提供的 **PUI Theme For OPlus 17，17.0.0.119** 中的 `PuiThemeBatteryHorizontal.apk`。只保留所需资源，未打包整个 PUI 模块；来源及校验见 [PUI 资源依据](docs/PUI-battery-evidence.md)。也可选择系统原生样式，其他电池形态继续使用系统绘制。

充电时，电池内电量数字与镂空闪电平滑切换。电池外形、数字、闪电、充电及低电量／省电填充颜色分别设置，位置、整体大小、宽高及动画时间可调。

颜色选择支持 HSB 调色盘、透明度及 RGB／ARGB 输入。透明度可跟随系统或独立设置。字体支持系统、内置苹方和自选字体；内置字体为必要字符的可变字体裁剪版本，其余字符由系统补齐，来源见 [字体说明](FONT.md)。

## 启用与更新

覆盖安装同签名 APK，在 LSPosed 中启用模块并选择 SystemUI 作用域。模块代码更新后重启 SystemUI；日常参数变更即时通知作用域应用。

设置页支持手动及启动时定期检查 [GitHub 正式发布](https://github.com/SANWU5/c17-statusbar/releases/latest)。检查仅在设置应用中运行，打开发布页／APK 链接供用户选择，不自动下载或安装；草稿、预发布和较旧版本不会作为更新提示。

大字号或大幅位移可能与其他项目重叠，解除内部裁剪不会扩大系统窗口或物理屏幕。当前适配依据为 OnePlus/Oplus SystemUI，其他 ROM 的控件和资源结构可能不同。

## 可选日志

日志默认关闭，可开启后复现问题，再查看、分享、下载或清空。记录固定阶段和异常类型，不保存异常原始消息、用户文本或参数原值。当前日志及一份轮转日志各限 512KiB，界面预览最新 64KiB；分享使用临时只读快照和系统选择器，下载使用系统文件保存界面。
